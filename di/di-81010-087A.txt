A. Information about the EDCS Routing Form
The field office (FO) uses the EDCS routing form to send folder documentation not
stored electronically in eView to the receiving office.
When transferring an electronic folder (EF), the FO can print the EDCS routing form.
If there is documentation (for example, medical evidence submitted by the claimant
and not faxed into the EF, or a paper Modular Disability Folder [MDF] associated with
the EF) to send, the FO:
•
prints the routing form;
•
attaches it to the documentation; and
•
mails it to the receiving office.
Do not print the EDCS routing form if there is no paper documentation.
IMPORTANT: Whenever possible, fax paper documents to the EF following the instructions in DI 81010.090, or scan document following the instructions in DI 81020.050.
NOTE: Any component can print the EDCS routing form at any time using the “Print Forms”
link in EDCS or eView.
