B. eRPC - The RPC tool
1. The RPC tool automatically:
•
Notifies adjudicating components, review components, Disability Adjudication (DA),
Quality Review (QR) and Disability Compliance (DC) when an RPC submission has been
accepted, when the case is scheduled for RPC panel discussion, and when DP posts the
resolution;
•
Provides a transparent vehicle to share resolutions with all users.
2. RPC uses the RPC tool to:
•
Manage the RPC process;
•
Manage user access to the RPC process;
•
Receive RPC requests;
•
Schedule RPC panel discussions;
•
Monitor the workload; and
•
Capture information from RPC cases that may be useful to operational, quality, or
policy components.
3. Adjudicating Components may use the RPC tool to:
•
Complete and submit RPC requests;
•
Add and remove users;
•
Assign more than one user to be an administrator to perform the user administrative
functions;
•
Assign any number of users to be RPC requesters;
•
View pending RPC cases; and
•
Perform data searches
4. Review components may use the RPC tool to:
•
View pending cases;
•
Voluntarily request a deficiency rescission prior to RPC panel discussion (see DI 30007.135D.).
5. QR and DA managers can:
View pending RPC cases.
6. DC users can:
Review cases from their regions and conduct data analysis.
NOTE: To add or remove users from the RPC tool, send an email to “^LP DP RPC
Controls” with the name and personal identification number (PIN) of the user to be added or
removed.
