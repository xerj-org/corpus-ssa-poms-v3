SSA Program Operations Manual System (POMS) - DI 23022.050 - Making the Determination in Compassionate Allowances (CAL) or Quick Disability Determinations (QDD) Fast-Track Cases
Effective Dates: 11/19/2018 - Present | TN 18 (11-18)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0423022050 (fetched 2026-10-04)

B. Removing the CAL and QDD indicator
Remove the CAL and QDD indicator if any of the following apply:
1. All claims in the case are denials
If all claims in the case are denials, remove the case from CAL and QDD processing,
using as a removal reason, “All Claims in the case are denials.”
2. All claims in the case are disability determination services (DDS) "no determination"
Use this removal reason if the DDS returns all claims in the case to the field offices
(FO) with no determinations.
3. Non fast-track action or development is required
Use this removal reason if any of the following apply:
•
Class action re-adjudication,
•
Clearly not a CAL case –remove CAL only,
•
Medical deferment,
•
Reactivation or reopening
For more information on removal reasons, see DI 23022.055 Actions on Compassionate Allowances and Disability Determinations Fast-Track Cases.
