B. IQF uses
Use the IQF to do the following:
•
Determine if a user established an IDR partial;
•
Determine whether the user submitted an IDR;
•
View data in IDR partials;
•
Print the IDR; and
•
Delete an IDR from the database.
NOTE: Do not query IDRs as a matter of routine. Generally, a query is not necessary if
the IDRD propagates to EDCS. Query an IDR partial to facilitate an interview or to
determine the protective filing date for an application.
