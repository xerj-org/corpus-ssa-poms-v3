DI 52165.001 Using the Interactive Computations Facility (ICF) to Compute Workers' Compensation
(WC) Public Disability Benefit (PDB) Offset and ICF Terms
Most actions for WC/PDB inputs are done using the ICF WC/PDB functions in the Title
II/Interactive Computations area. The Title II/Interactive Computations is located
under option #7 on the Main Menu in Personal Communications (PCOM).
The WC/PDB ICF functions are used to make post-entitlement (PE) inputs and when a
claim cannot be properly computed in the Modernized Claims System (MCS) Earnings Computation
(EC).
•
ICF functions #31, #32, and #34 are the primary functions used to compute and input
WC/PDB offset.
•
ICF function #33 is used to query or print WC/PDB data.
•
ICF functions #9 and #28 are sometimes used for computations, but due to system limitations,
are used cautiously.
