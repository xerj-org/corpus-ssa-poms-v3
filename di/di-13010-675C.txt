C. How to read and complete the VERN screen
Each VERN screen contains information for one month, beginning with the first month
requested from the MCDR screen. When you complete inputs for the month: use thePF8
function key, or, the REPEAT indicator option to access the VERN screen for the next
month. The REPEAT function copies work information entered on the current screen to
the next VERN screen.
VERN screens are in a sequence for a maximum of 48 months. When all necessary screens
are completed, hit ENTER to return to the MCDR screen to save your entries.
Refer to MSOM CDR 002.002 for a complete description of the input and display fields.
