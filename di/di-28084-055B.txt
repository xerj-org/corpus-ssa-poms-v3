B. Procedure for completing Item 29
1. If legally competent beneficiary has representative payee
If the disabled individual is legally competent and has a representative payee, the
disability examiner (DE) must:
a.
Enter “S” and modify typing instructions.
b.
Address and send the notice to the disabled individual at the individual's mailing
address.
c.
Address and send a modified copy of the notice to the representative payee.
2. If modification of stock paragraph(s) is required
When modification of one or more stock paragraphs is required, the DE must show “DDS-D/L”
or “ODO/INTPSC/PSC-DRS-D/L.”
3. If model letter is required
When a model letter is required, the DE must show the letter number (e.g., SSA-L951-U2
(Social Security Notice Letterhead), SSA-L4967-U2 (Social Security Notice of Reconsideration
Disability Benefits)).
NOTE: For specific a model letter, see NL 00701.003.
4. If no model letter is required
When no letter is required, the DE must show “NLN” (no letter necessary).
