SSA Program Operations Manual System (POMS) - DI 52145.015 - Retention of Workers’ Compensation/Public Disability Benefit (WC/PDB) Proofs
Effective Dates: 08/29/2023 - Present | TN 4 (08-23)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0452145015 (fetched 2026-10-04)

A. Retaining WC/PDB proofs
1. Field Office (FO) actions:
•
Electronic folder (EF) established:
Always fax all WC/PDB proof documents into the EF. Documents can still be faxed into
the EF if the Electronic Disability Collect System (EDCS) case is closed. See Faxing
Documents into the Certified Electronic Folder (CEF) Using Barcodes, DI 81010.090. If Processing Center (PC) action is required, also fax material into the Paperless
Processing Center (PPC) system using the Evidence Portal (EP). For additional information
on EP, see MS 09701.001.
These systems will allow for later viewing of proof documents by FO and PC personnel.
•
Paper folder established:
Fax all WC/PDB proof documents into the Non-Disability Repository for Evidentiary
Documents (NDRed) using EP. If the paper folder is present in the FO, retain a copy
of the source proof in the paper file. If PC action is required, also fax the material
into Paperless using EP.
2. Processing Center (PC) actions:
•
Electronic folder (EF) established:
Always fax all WC/PDB proof documents secured by PC personnel into the EF, in addition
to Paperless, so the FO can view the documents (remember, FOs cannot access Paperless).
See Faxing Documents into the CEF Using Barcodes, DI 81010.090.
•
Paper folder established:
Always scan or fax all WC/PDB proof documents into NDRed using EP, so the FO can view
the documents (remember, FOs cannot access Paperless). Retain a copy of the source
proof in the paper file, if the folder is physically present when the action is taken.
