D. Reminders of choosing an impairment code for cancers
•
If the cancer meets or equals 113.03, use the impairment code for cancer of the affected
body part. For example, if the cancer is in the skeletal system (e.g., bone), use
1780.
•
If the cancer meets listing 13.05, 113.05, or 13.28 based on bone marrow or stem cell
transplant, use 0420 as the primary impairment code. Use the code for the specific cancer type as the
secondary impairment code.
NOTE: For additional information on how cancer is evaluated under the listings, see DI
34005.113.
