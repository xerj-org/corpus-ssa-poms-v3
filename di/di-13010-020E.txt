E. Work report pending
If a work report for the same employer is pending in eWork:
1.
Determine if the current report will change the information from the prior report,
or is a report for a new period of employment. If the report:
•
is for a new period of employment, select “Add”; or
•
involves work from the same period of employment that is already shown, select “Edit.”
2.
Issue a new receipt if the reporter is the beneficiary, the representative payee,
or appointed representative.
