SSA Program Operations Manual System (POMS) - DI 24583.060 - Additional Guidelines for Using Psychological Tests to Evaluate Mental Disorders in Children
Effective Dates: 05/26/2023 - Present | TN 5 (05-23)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0424583060 (fetched 2026-10-04)

A. How are psychological tests used to evaluate childhood disability claims?
Psychological tests for children must satisfy the same requirements as psychological
tests for adults. However, there are additional guidelines that are specific to psychological
tests for children. For more information about psychological tests, see DI 24583.050. For more information about intelligence tests, see DI 24583.055.
