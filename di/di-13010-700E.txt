E. Procedure - Reading the NDNH T-II DIB QUERY
The NDNH screen contains information on both wage and unemployment reports. If there
is a “Y” in either column, there is a report for that quarter.
Overkey the “Y” with an “X” to view information for each quarterly report and hit
Enter.
