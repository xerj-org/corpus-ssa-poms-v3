E. Reminders for choosing an impairment code for immune system disorders
•
Use impairment code 0430 as the primary impairment code for a favorable determination based on HIV infection.
•
Do not use 0440 as the primary impairment code for a favorable determination. Because the primary
impairment code is the basis for the allowance, this would mean the determination
was based on HIV infection which has no symptoms, signs, or manifestations.
•
Use impairment code 1390 for any opportunistic infection that is associated with symptomatic HIV infection.
This includes any bacterial, viral, parasitic, or fungal disease. Examples of diseases
under this code include: toxoplasmosis, candidiasis, salmonella bacteremia, herpes
simplex, cytomegalovirus, and syphilis.
•
If DI 33526.070D does not include an impairment code for the HIV manifestation, and impairment code
1390 would not be appropriate, use a code from the list of impairment codes for the appropriate
body system.
