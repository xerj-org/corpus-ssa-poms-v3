DI 10115.020 Application Forms for Childhood Disability Benefit (CDB)
Policy
Use the following application forms for CDB:
Form
Description
SSA-4-BK
Application for Child's Insurance Benefits
SSA 3368
Disability Adult Report form for Title II Disability Benefits
SSA-827
Authorization to Release Medical Information to the Social Security Administration
SSA 820/821
Report of Work Activity
A summary of the nondisability evidence required in initial entitlement cases can
be found in RS 00203.040. Processing instructions for CDB claims are found in DI 11020.000.
