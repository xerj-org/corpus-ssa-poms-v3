SSA Program Operations Manual System (POMS) - DI 28501.030 - Routing Reopened Continuing Disability Review (CDR) Cases
Effective Dates: 08/28/2025 - Present | TN 6 (08-25)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0428501030 (fetched 2026-10-04)

D. If case has an MDF and a CEF
Always send the MDF comparison point decision (CPD) folder to the same office that
you transfer the CEF. For both folders, include messages about what action is necessary,
if any. Follow the routing instructions as given in DI 28501.030B in this section. If OQR selects a case for review, route as appropriate.
