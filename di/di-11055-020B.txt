SSA Program Operations Manual System (POMS) - DI 11055.020 - Using the Electronic Disability Collect System (EDCS) to Collect the Claimant’s Disability Information
Effective Dates: 09/03/2009 - Present | TN 64 (09-09)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0411055020 (fetched 2026-10-04)

B. General Definitions
•
A claim refers to each individual Title XVI or Title II application.
•
A case consists of all claims at the same adjudicative level, sharing the same disability
report form (SSA-3368, SSA-3820, or SSA-3441), which are adjudicated using the same
medical evidence. Create a new “case” for each adjudicative level.
•
A filing consists of all claims adjudicated together through all case levels (initial, reconsideration,
or hearing). For example, consider concurrent claims adjudicated through all appeal
levels as a filing. Every new filing begins with a new initial application or applications.
Each filing must be either a Certified Electronic Folder (CEF) or paper Modular Disability
Folder (MDF).
