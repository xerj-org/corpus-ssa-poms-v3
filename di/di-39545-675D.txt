D. Use the Medicare fee schedule to determine the Medicare fee for each service ordered
by the DDS
•
Document the DDS code that matches the CPT code for each specific exam/ancillary study.
•
Annotate the CPT code as the control code. For each CPT control code, document the
DDS fee along with each Medicare fee.
