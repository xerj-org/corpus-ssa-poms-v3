B. Policy - EC
EC provides the yearly earnings and the insured status determination, along with the
primary insurance amount (PIA) if the individual is insured. Since EC provides the
computation information, it is rare that there is a need to go outside of MCS to use
the Informational/Certified Earnings Record System (ICERS) to obtain an earnings record
(E/R). Review the Earnings Alert Query (EARQ) for earnings alerts.
