SSA Program Operations Manual System (POMS) - DI 28084.060 - List Numbers (Item 34)
Effective Dates: 10/27/2015 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0428084060 (fetched 2026-10-04)

B. Procedure to complete Item 34
Enter in Item 34, when appropriate, a three-digit code to identify cases with specific
characteristics for later review. For a list of active disability listing codes, see
DI 33530.005.
1. Multiple codes
Enter each code in a separate block of Item 34.
2. Coding order
Enter codes in Item 34 in any order except when there are procedures to do otherwise,
e.g., Office of Quality Review (OQR) list codes, which identify cases for automatic
sample selection in special review situations, are entered in Block 34C, even when
there are no other codes entered in Blocks 34A and 34B.
3. Code maximum
Enter a maximum of six codes in Item 34.
