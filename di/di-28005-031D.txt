D. Completion of the SSA-832 for continuances
1. Remarks and list codes for the SSA-832
Based on the facts in a continuance, enter the appropriate remark and list code from
the following table in items 24 and 34 of the SSA-832 respectively. Every Title XVI
childhood CDR continuance must have a list code in item 34 on the SSA-832-C2/U3.
NOTE: The National Disability Determination Services System (NDDSS) requires a list
code for all continuance determinations for DC CDRs. The DDS will receive an edit
message "T16 CHILDHOOD CASE REQUIRES LIST CODE" if a list code (281 - 287) is not
entered in the LA - LF fields. To clear this edit, enter the appropriate list code
and remark from the table above. See SM 06001.920E.
