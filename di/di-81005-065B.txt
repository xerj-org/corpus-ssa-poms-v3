B. Printing Disability Reports
Once the FO transfers jurisdiction of the EDCS case to the DDS, printouts of the disability
report will reflect case information as it existed at the time of transfer. FO updates
to the disability report information or work history information must be recorded
and transmitted using the EDCS Update-After-Transfer (UAT) utility. (For more information,
see DI 81010.095.)
1. Printing from the “Print Forms” Link
The “Print Forms” link appears on the primary title bar in eView tab and allows users
to print documents from each case level (one case level at a time) in EDCS. To print
form(s) from the Print Forms link:
a.
Click the Print Forms link,
b.
Select the case level,
c.
Select the form(s) to print, and
d.
Select “Print and Exit” or “Print and Return”.
To print a routing form, select the appropriate adjudicative level and click the Routing
Form button.
2. Printing from Forms View
The Case Data view appears under the Case Data tab in eView. Users can produce a printout
of all data in a specific section of the disability report one section at a time.
To print data from a specific section from Case Data view:
a.
Select the Case Data tab,
b.
Select the section from the Case Data navigation tree,
c.
Right-click on the mouse and select “Print” from the pop-up menu, or,
d.
Use the keyboard command <CTRL> and <P>.
The printout includes all data in the selected section from all adjudicative levels.
For details on the Case Data tab, see DI 81005.045.
3. Printing from Case Data View
The Forms View appears under the Case Data Tab in eView within the Forms folder located
at the bottom of the Case Data Navigation Tree in eView.
In order to print a form from the Forms View, the user must:
a.
Select the Forms folder,
b.
Select the case level folder,
c.
Select the form folder of the desired form,
d.
Select the form by viewing the hyperlink to any section of the form, and
e.
From the navigation bar at the top of the form section, click on the “Print the Form”
link on the upper left part of the screen.
4. Printing from the Case Documents Tab
The Case Documents tab allows users to view the electronic display of the Modular
Disability Folder (MDF). To print a PDF of form(s) from the Case Documents tab:
a.
Select the Case Documents tab,
b.
Expand the section(s) of the electronic folder to reveal the documents in each section,
c.
Select the appropriate document(s) by checking the selection box, or,
d.
Choose to print all documents in the expanded section(s) by clicking Select “All”
on the color coded section title bar of each section,
e.
Select the “Print” button at the bottom of the page, and click OK,
f.
View the generated PDF file that contains the requested documents in the order they
appear in eView and a document index page listing the documents selected for printing,
and
g.
Print the PDF from Adobe Reader.
This will print the PDF, including all selected document(s) and an index of all printed
documents.
