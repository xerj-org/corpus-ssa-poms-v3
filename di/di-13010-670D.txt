D. Procedure - Reading the QWID Screen
The QWID provides the work information applicable for each work event listed on the
QCDR screen. A QWID screen will appear for each work CDR event listed on the QCDR.
The fields on each screen are:
•
The WORK START DATE field provides the date the work activity investigation began
(the initiation date). This date will normally be different than the date the beneficiary
actually started working (the WORK FIRST MONTH).
•
The WORK END DATE provides the date the work activity investigation ended (the closing
date).
•
The WORK DECISION DATE provides the date the decision was made for the event.
•
The WORK ENFORCEMENT AMOUNT provides the amount of earnings reported for the year
(in whole dollar amounts).
•
The WORK FIRST MONTH field is the month and year the beneficiary actually started
working.
•
The last field on this screen is the WORK LAST MONTH and provides the month and year
the beneficiary stopped working.
