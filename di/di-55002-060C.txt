C. Procedure—use of the ticket add/terminate screen (TATS) to add or terminate a ticket
The TATS screen allows an authorized user to add or terminate a Ticket.
NOTE: The TATS screen will perform two mutually exclusive functions. It will display either
an ADD Ticket Screen or a Terminate Ticket screen only.
1. Access the TATS screen
To access the TATS screen:
•
select 32, “Continuing Disability Review File”, from SSA's main menu (MAIN)
•
select 11, “Ticket to Work”, and SSN or SSN and BIC on the MCDR screen
•
select 8, “TATS” and place an “X” next to Ticket Number on the Ticket Submenu TMEN) screen.
•
Press “ENTER” and the ADD TICKET or TERMINATE TICKET screen will be displayed.
2. Terminate a ticket
•
Select a reason 1 through 8 from the TERMINATE TICKET REASON field
•
Press “ENTER” to return to the TMEN screen.
3. Add a ticket
•
Select “Y” (Yes)
•
Press “ENTER” to return to the TMEN screen.
