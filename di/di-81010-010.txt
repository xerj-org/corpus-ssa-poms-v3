DI 81010.010 Office Code Utility
Many Electronic Disability Collect System (EDCS) and eView pages display an office
code that identifies the office with jurisdiction. To activate the office code utility,
select the office code utility/link to view details about the office including the:
•
Office name;
•
Address and;
•
Administrative telephone number.
On some pages, the office code itself is the link that displays detailed office information
when selected. Other pages contain an “Office Description” link next to the office
code that displays the same information when the link is selected.
