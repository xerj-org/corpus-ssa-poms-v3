E. Procedure – obtaining a “Ticket Use History” query
1. Access the TKUH screen:
To accessed the TKUH screen:
•
select 32, “Continuing Disability Review File” from SSA's main menu (MAIN);
•
select 11, “Ticket to Work,” from the CDR Selection Menu (MCDR) and enter the ticket
holder's SSN; and
•
select 7, “Ticket Use History” from the Ticket Submenu (TMEN).
2. MSOM references
MSOM CDR 004.008 provides information on how to read the fields on TKUH screen.
