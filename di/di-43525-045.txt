DI 43525.045 Beneficiary Wishes to Return Checks or Requests Suspension of Benefits
When a beneficiary wishes to return a check or requests suspension of benefits to
which entitlement has been established, determine the reason for the request for such
action. If it is clear that the beneficiary is nevertheless entitled, be sure the
beneficiary understands this. If the beneficiary still wishes to return checks or
have benefits suspended, comply with the request. (See GN 02403.001 and GN 02409.001.)
