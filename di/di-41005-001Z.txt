3.
Item 33 - Date
Enter date of signature in item 31.
4.
Item 34 - List No.
See DI 33530.005 for a discussion of list codes. The specific code, where applicable, is to be entered
in this item. If the disabled individual is permanently impaired, enter the related
list code if the case has not been listed previously under that code.
5.
Item 35 - Folder Sent To
Designate where the folder is being routed. If case is routed to the Program Service
Center (even if first routed to the DQB), show “NEPSC, MATPSC, SEPSC, GLPSC, MAMPSC, or WNPSC” as appropriate. If disability examiner action is required, route the case first to
the DRS, e.g., NEPSC-DRS, MAPSC-DRS, etc.
The routing designation is for external routing only; i.e., if an ODO examiner routes
to a benefit authorizer within ODO, no entry would be made. However, if the ODO examiner
routed the folder to a PSC, they would enter that PSC.
