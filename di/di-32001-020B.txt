B. Final folder review
1.
Examine the contents of the case file to make sure that the number holder's name and
Social Security number appear on the first page of each document. Do not to write
on, mark, or underline evidence submitted other than to identify the material.
2.
Ensure that all the material in the file applies to the claimant. If the folder contains
material that does not apply to the claimant, associate the material with the proper
file. If there is no claim in the DDS to relate the material with, handle it as trailer
material. See DI 22520.000.
