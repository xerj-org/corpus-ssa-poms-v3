D. Reminders for choosing an impairment code for neurological disorders
When you are choosing an impairment code for neurological disorders, keep the following
in mind:
•
Use impairment code 3350 only if the established diagnosis is amyotrophic lateral sclerosis (ALS). See DI
24580.020D3.
•
Use impairment code 3358 if the established diagnosis is a motor neuron disorder other than ALS, for example,
progressive bulbar palsy, pseudobulbar palsy, spinal muscular atrophy (SMA), or primary
lateral sclerosis (PLS).
•
Do not use impairment code 3480 for a medically induced coma. Use the impairment code for the underlying disorder
causing the need for a medically induced coma.
