SSA Program Operations Manual System (POMS) - DI 11025.030 - Disability Determination Needed to Entitle a Dependent Grandchild
Effective Dates: 03/04/2011 - Present | TN 2 (09-22)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0411025030 (fetched 2026-10-04)

D. DDS determination received
1. Parent disability allowed
If DDS allows the parent’s disability:
•
Fax and store a copy of the parent’s SSA-831 in the Non-Disability Repository for
Evidentiary Documents (NDRED) using the Evidence Portal (EP) since the parent’s disability
folder is a paper folder. You can access the EP at View Evidence-Evidence Portal (ssa.gov)
•
On the CREL screen in MCS, show that the claimant provided proof and show the relationship
type as 5-Grandchild.
2. Parent disability denied
If DDS does not allow the parent’s disability:
•
On the CREL screen in MCS, show that proof of relationship was not provided. Since
both parents are not deceased or disabled, the child does not meet the definition
of grandchild for SSA purposes.
•
If the denial code is not automatically generated, use disallowance code 25-not a
grandchild.
•
Complete the NOT3 (Notice 3) to request PC to add a dictated paragraph to the disallowance
notice to explain the denial. DDS does not send a notice.
