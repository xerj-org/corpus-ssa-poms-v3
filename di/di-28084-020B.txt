B. Procedure for completing Item 12
Enter the following information:
•
the appropriate “Reason for Continuance” code from the lists in DI 28084.020C in this section into the “CODE” block of Item 12;
•
only one “Reason for Continuance” code even if more than one code could apply; and
•
if the continuance code is 30, 32, 70, 71, 72, or 73, enter the appropriate medical
listing number in Item 12 of the Forms SSA-832 or SSA-833.
