D. Case transmission
For more information about processing a reconsideration appeal of an eCDR cessation,
see DI 81020.255B.1.b.
For paper cases, follow these instructions to transmit the case to the DHU:
1.
Update the case control system using the appropriate DDS or DHU code as the destination
code. The appropriate destination code may vary based on local operating procedures;
2.
Use an SSA-408 (Route Slip) to send the case to the DHU and annotate it to alert the DHU to any
special situations (e.g., associated new claim, section 301 cases, drug addiction
or alcoholism (DAA), prisoner case); and
3.
Hand-deliver the case if the DHU is co-located with the DDS. Otherwise, mail it or,
if possible, use a courier service to speed delivery.
