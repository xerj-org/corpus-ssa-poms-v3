SSA Program Operations Manual System (POMS) - DI 20505.015 - Disability Determination Services (DDS) Actions to Obtain a Prior Paper Folder
Effective Dates: 11/03/2017 - Present | TN 8 (01-23)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0420505015 (fetched 2026-10-04)

E. DDS determines the prior folder is unnecessary
If the DDS determines the requested prior folder is not necessary, prepare a determination
on the current claim and forward it per DI 32001.010B.
If the DDS receives the prior folder after the denial determination, the DDS forwards
the folder to the FO to be associated with the current claim and retained for 6 months.
If the DDS allows the current claim, DDS sends the prior folder for association with
the current folder.
In some situations, the FO will recall both the current folder and a related folder
that the PSC/ODO may have sent to the DDS. In this instance, stop development and
return the entire claims folder to the FO. If the DDS later receives a prior folder,
send it to the appropriate or corresponding FO.
