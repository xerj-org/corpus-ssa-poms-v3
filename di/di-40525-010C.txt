SSA Program Operations Manual System (POMS) - DI 40525.010 - Processing Conversion Cases—Reduced Retirement Benefits (RIB) to Reduced Disability Insurance Benefits (DIB)
Effective Dates: 10/03/2002 - Present | TN 1 (10-02)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0440525010 (fetched 2026-10-04)

C. Procedure – action upon folder review
1. No CDR issue
If no CDR issue exists:
•
Prepare a SSA-833-U3 determination, annotate “DIB Conversion” in item 1B of the SSA-833-U3,
and “Conversion from reduced RIB to reduced DIB—no current continuing disability issue
exists” in item 24 of the SSA-833-U3.
•
Route folder to claims authorizer (CA) stating “SSA-16-F6 filed for reduced DIB. Disability
action completed—no new SSA-831-U3 is needed.”
2. CDR issue exists
If a CDR issue exists:
•
Prepare development request per DI 40525.010C.3.
•
If the RIB benefits have been terminated, route folder to BA and annotate route slip,
“Reinstate RIB benefit pending CDR to avoid an interruption to benefits.”
3. Routing cases
When routing these cases, if folder involves:
a. A medical issue
If the folder involves a medical issue, then:
•
Route the folder to the DDS via a SSA-847-U3 and
•
Request that the DDS prepare a SSA-833-U3 after development has been completed.
b. A work issue
If the folder involves a work issue, then:
•
Route the folder to the FO via a SSA-5526-U3 and
•
Request that the FO prepare a SSA-833-U3 after development has been completed, or
•
The PC DRS is to develop the case and prepare a SSA-833-U3.
c. Both medical and work issues
If the folder involves both medical and work issues, then:
•
Route the folder to the FO and
•
Request that the FO send the folder to the DDS after action has been completed.
4. Folder returned
When the folder is returned, proceed as follows:
•
Review the SSA-833-U3, including the disability profile data,
•
Enter “DIB Conversion” in items 1B and 24 of the SSA-833-U3.
•
Route the folder to CA per DI 40525.010C.1.b.
