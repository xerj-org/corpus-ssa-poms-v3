B. OREO limitations
The OREO program has limitations. If you cannot process a case using a single OREO,
manually code the WC benefit data into MACADE. Even for OREO limitations, the case
may require one or more OREO inputs in order to process the case. See OREO Limitations
- MSOM ICFT2 036.001G.
