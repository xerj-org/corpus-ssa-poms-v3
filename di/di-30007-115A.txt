A. Introduction
The RPC website is available on SSA’s intranet, and contains links, tools, user guides,
and other information related to the RPC process. Individual security settings determine
access to specific functionality within the website. For example, from the RPC website
homepage, most users may:
•
See the RPC panel discussion schedule using the “RPC Discussion Meeting Schedule”
function.
•
View specific case summaries, rationales, citations, and RPC resolutions.
•
Search for an RPC case based on specific criteria (such as RPC case number, body system,
policy issue, etc.) using the “Search Data” function.
•
Access management information (MI) regarding RPC cases using the “MI Reports” function
and the Management Information Dashboards.
•
Access detailed user guides using the “user Guides” link.
