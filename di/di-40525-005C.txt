SSA Program Operations Manual System (POMS) - DI 40525.005 - Processing S-0 Alerts
Effective Dates: 01/14/2010 - Present | TN 1 (10-02)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0440525005 (fetched 2026-10-04)

C. Procedure
1. Alert received with temporary folder
If the alert is received with a temporary folder, determine the location of the folder
and proceed as follows:
a. Permanent folder in FO, DDS, or Office of Disability Adjudication and Review (ODAR)
If the permanent folder is in the FO, DDS, or ODAR:
•
Use systems query to determine the status of the CDR;
•
If status of CDR is not apparent from query, call component holding permanent folder
to determine status of CDR;
•
Annotate S-0 alert with reported status;
•
Sign and date alert;
•
Return alert and temporary folder to files.
b. Permanent folder in another PC
If the permanent folder is in another PC:
•
Determine which component has proper jurisdiction of the folder;
•
Forward S-0 alert to the component holding permanent folder; or
•
Request transfer of permanent folder, as necessary. When received, process per DI 40525.005C.2.
•
Delete temporary folder, if appropriate.
c. Folder not in recorded location
If the folder is not in the recorded location, undertake a complete folder search.
