K. Special Flags
Flags will continue to be used to identify special case handling situations (e.g.,
terminal illness (TERI), acquired immunodeficiency syndrome (AIDS) and amyotrophic
lateral sclerosis (ALS). See DI 81010.080 for CEF case flag instructions. See DI 23020.045 for a TERI flag exhibit and list of descriptions when this flag is used.
