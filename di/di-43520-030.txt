DI 43520.030 Completion of the SSA-831-U5 by the DO Function - Title II Claims
CDA's, CA's, and DO personnel will complete items 1-14 of the SSA-831-U5 as described
in DI 11015.000 with the following exceptions:
Item 2 - DDS code.
Claims filed by an on behalf of residents of foreign countries will reflect 670 for
the DDS code.
Item 12 - District - Branch Office Address and DO/BO Code
For claims originating in CDB enter INTPSC, PO Box 17769, Baltimore, MD 21203, Code
Q85. For claims originating in the Philippines, enter the Foreign Service Post in
Manila, Philippines, APO San Francisco, 96528, Code 994.
All other claims should show the address and code of the originating DO-BO of origin.
