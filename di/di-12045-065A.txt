SSA Program Operations Manual System (POMS) - DI 12045.065 - Career Railroad Retirement Board (RRB) Cases When Claimant Files an Appeal
Effective Dates: 09/17/2013 - Present | TN 12 (04-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0412045065 (fetched 2026-10-04)

A. Claimant files a request for reconsideration
If a claimant files a SSA-561-U2 (Request for Reconsideration), the field office (FO)
must:
1.
Establish the appeal in the Modernized Claims System (MCS)/Modernized Supplemental
Security Income Claims System (MSSICS) using the Appeals Program (Banana) or manually
enter information into the appeal screens.
2.
Establish the appeal in the Electronic Disability Collect System (EDCS), unless the
claim is an EDCS exclusion.
3.
For forms required for filing a reconsideration, see DI 81010.150C.
4.
If the case is EDCS, and you must transfer the case to the Great Lakes Program Service
Center (GLPSC)-Disability Case Review (DCR), code V32, refer to DI 11050.055.
5.
If the case is an EDCS exclusion, follow DI 11050.060 and send the SSA-561-U2 to:
GLPSC
Disability Case
Review
(Office Code V32)
P.O. Box 87755
Chicago, Illinois 60680-0955
NOTE: To process an iAppeals i561, see GN 03101.125.
