B. Procedure – obtaining a “Ticket to Work Query”
1. Access the DIBT screen
To access the DIBT screen:
•
select 9, “Master File Query,” from SSA's main menu (MAIN);
•
select 17, “Inquiry Response” from the Master File Query Menu (MFQM) and enter the
ticket holder's SSN;
•
select H, “Disability,” from the Query Response Selection List (QRSL); and
•
select 8, “ticket,” from the “Select Subject Queries” list that appears at the bottom
of the General Disability Query (DIBG) screen.
2. Modernized Systems Operations Manual (MSOM) reference
MSOM QUERIES 006.011 provides information on how to read the fields on the DIBT screen.
