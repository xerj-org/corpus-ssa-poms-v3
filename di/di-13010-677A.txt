A. When to use the ESEL screen
Use the ESEL screen to select the claim that you want to input earnings via the Verify/Update
Earnings (VERN) screen, or query via the Query Earnings (QERN) screen. Prior to receiving
the VERN or QERN screens, you will select a claim from the ESEL screen.
