SSA Program Operations Manual System (POMS) - DI 24555.005 - Using Laboratory Testing to Evaluate Genitourinary Impairments
Effective Dates: 08/23/2022 - Present | TN 11 (02-25)

A. Background
This section provides information about laboratory testing we use to evaluate genitourinary
disorders under the criteria in listings 6.05, 106.05, and 6.06. We can also use laboratory
test results when evaluating residual functional capacity.
For more information about evaluating chronic kidney disease, see DI 34001.020 and DI 34005.106.
