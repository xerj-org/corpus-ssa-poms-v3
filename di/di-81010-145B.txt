B. Title II Claims MCS Processing
1. Reconsideration on MCS
If a Failure to Cooperate (FTC)/SGA/technical denial is affirmed, process the unfavorable
reconsideration decision through MCS;
If a FTC/SGA/technical appeal denial is reversed, do NOT establish a reconsideration
segment on MCS. Instead, document the special determination and send the interim notice
described in Processing a Reconsideration Request of an Initial Denial Based on Non-medical
Issues - DI 12005.010 in the reestablished MCS claim per Processing Reconsideration Request of FO Determinations
- DI 81010.145B.2.
NOTE: When a claimant, denied for failure to cooperate, later submits the requested development,
e.g., signed SSA-827s, within the appeal period, treat it as an implied request for
reconsideration.
2. Reestablish the initial disability claim on MCS
The previously denied initial disability claim has to be reestablished on MCS. Create
a new segment on MCS, using the original application/protective filing date, before
sending the claim to DDS for a disability determination. The application receipt date
is the date the FO received the request for reconsideration or implied request for
reconsideration. The material file date (MFD) should be the same as the application
receipt date. Enter the FDC of C on the DECI screen for (MI) purposes. The FDC code
of C will exclude the time, from the original application date through the new application
receipt date on the new DW01, from FO1 time. However, the time will not be excluded
from the mean overall time on the case.
