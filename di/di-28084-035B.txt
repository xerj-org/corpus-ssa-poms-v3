B. Special situations
Use the specific coding instructions for a CDR on the following situations:
a.
Do not use code 7649 (Low Birth Weight 1200 to 2000 Grams) or code 7650 (Low Birth
Weight to Weight Under 1200 Grams) for a continuance determination for a low birth
weight CDR. Low birth weight is not a medically determinable impairment (MDI) after
the attainment of age one; and
b.
Do not use code 0000 (None Established – No Medical Evidence in File) as the primary
code in Item 21. This code is a system limitation for posting CDR determinations to
the Master Beneficiary Record (MBR).
