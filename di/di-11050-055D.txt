SSA Program Operations Manual System (POMS) - DI 11050.055 - Transferring Electronic Disability Collect System (EDCS) Cases to Branch 2A of Disability Case Review (DCR)
Effective Dates: 10/01/2026 - Present | TN 7 (10-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0411050055 (fetched 2026-10-04)

D. Transferring Case to DCR
1.
Include a signed and dated SSA-827 in EDCS using any of the acceptable signature methods
listed in DI 11005.056A.2.
2.
Transfer claims in EDCS to V32, and mail any medical evidence of record (MER) or the
MDF if required (see NOTE below), with the EDCS Routing Form to:
DCR,
Branch
2A
P.O. BOX 87755 3RD FLOOR
Chicago IL. 60680-0955
Do
Not Open in Mailroom
NOTE: If a case is a certified electronic folder (CEF) exclusion, but is not an EDCS exclusion,
a Modular Disability Folder (MDF) must be created and forwarded. See Certified Electronic
Folder (CEF) Exclusions and Limitations, DI 81010.030.
