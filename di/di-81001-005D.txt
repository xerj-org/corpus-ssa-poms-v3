D. Accessing the CEF or EF
Access the CEF or EF through:
•
eView - for instructions on how to access eView, see DI 81005.005; and
•
Case processing systems (e.g., EDCS, Disability Case Processing System (DCPS), DDS
legacy systems, Disability Case Adjudication and Review System [DICARS], Case Processing
and Management System [CPMS] and Appeals Review Processing System [ARPS].
The Personal Identification Number (PIN) of an employee logged onto a workstation
controls the amount of access and functionality an individual has in the EF or CEF.
For more information about user access to the EF, see DI 81001.025.
