C. Procedure – Accessing the Query
To access the query:
•
Select 9, the Master File Query (MFQM), from the SSA Main Menu.
•
Select 7, the Data Exchange Query Menu (DXQM) from the Master File Query menu (MFQM),
and enter the SSN.
•
Select 4, NDNH T-II DIB from the DXQM menu.
NOTE: There is a similar query, NDNH T-XVI (Selection 1) on the menu. Access to this path
will be denied without the correct security profile.
