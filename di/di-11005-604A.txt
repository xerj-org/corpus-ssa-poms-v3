A. What is a CAL case?
A CAL case is part of a fast-track process designed to quickly identify claimants
with an impairment on the list of CAL conditions. This process allows us to expedite
determinations and decisions on these cases. Although CAL cases are processed more
quickly, the claimant must still be disabled as defined in the Social Security Act,
and we evaluate the claim using the same sequential evaluation process as all other
claims.
The CAL initiative is not a separate program from Social Security Disability Insurance
(SSDI) or Supplemental Security Income (SSI); all the same entitlement or eligibility
requirements for these programs still apply. We identified a specific list of impairments
that are very severe, typically have a poor prognosis, and are highly likely to result
in an allowance. For the list of CAL conditions, see DI 23022.080.
