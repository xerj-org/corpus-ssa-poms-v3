A. When a special senses or speech impairment meets or equals a Part A listing
Use the appropriate impairment code from the following table if the special senses
or speech impairment meets or equals a Part A listing. When the impairment meets listing
2.02 or 2.03A, see DI 26510.015C. If a code in the table has an asterisk (*), see the reminders in DI 33526.010D.
