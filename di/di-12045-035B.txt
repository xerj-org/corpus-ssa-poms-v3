SSA Program Operations Manual System (POMS) - DI 12045.035 - Same Title Claims – New Claim or Appeal Filed, Prior Claim Pending at the Hearing Level
Effective Dates: 04/05/2012 - Present | TN 1 (11-02)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0412045035 (fetched 2026-10-04)

B. Procedure
1. New Claim
•
Do not undertake any development or request the prior claim file from the Hearing
Office (HO). Do not prepare a folder.
•
Certified Electronic Folder -- Follow DI 81010.095 Using the Update-After-Transfer (UAT) Utility.
•
Paper Folder -- Forward the new claim immediately to the ALJ.
2. Appeal
If a claimant requests an Administrative Law Judge (ALJ) hearing and the case control
query shows that the needed claim folder is in a HO, take the following actions:
a.
Contact the office indicated on the query to determine whether the current appeal
request is a duplicate, or if the folder shown on the query is a prior claims file.
b.
If the request is a duplicate, proceed as follows:
•
Prepare a Report of Contact (RC) indicating the location of the folder and that the
current request is a duplicate.
•
Forward the RC with the ALJ copy of the appeal request to the appropriate hearing
office.
c.
If the request is not a duplicate follow DI 12010.001 to process the request.
