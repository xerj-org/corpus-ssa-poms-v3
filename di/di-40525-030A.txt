A. Process - Automated Direct Release (ADR)
The ADR process works as follows:
1.
Near the beginning of each Fiscal Year (FY), the Office of Continuing Disability Reviews
Support (OCDRS) prepares a file for the Office of Systems (OS) to create a file of
all “available” direct release continuing disability reviews (CDRs) for the ADR process.
2.
The ADR process allows for regular monthly direct release CDR selections throughout
the year based on the file of potential candidates for that FY furnished by OD.
3.
The ADR process is currently set to run one “primary direct release” selection monthly
for either Title XVI or Title II and Concurrent Title II/XVI CDRs.
4.
ADR produces a file that will update the Disability Control File (DCF).
