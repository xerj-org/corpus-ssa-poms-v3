D. Building the Supplemental Security Record (SSR)
1. Electronic application
MSSICS initiates a process referred to as Build Transaction SSR (BTS). The BTS process builds the application information to the SSR, producing the Supplemental
Security Income Display (SSID) query for the SSI claim.
Reference:
MSOM BUSSR 001.002 Build Transaction SSR (BTS)
2. Paper application
When the SSI claim is an exclusion from processing in MSSICS, use Form SSA-450SI (SSI
Data Input and Determination) to transmit the application information needed to produce
the SSID query for the SSI claim.
