Effective Dates: 05/01/2023 - Present | TN 7 (10-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0411050060 (fetched 2026-10-04)

A. Transferring Electronic Disability Collect System (EDCS) exclusions
If the case is an EDCS exclusion, see DI 81020.000 then transfer as follows:
•
Create the DDSDEC issue and set a 90-day tickle on the Development Worksheet for MCS/the
Consolidated Claims Experience (CCE).
•
Show the DDS code of V32 on the ADIB (MSSICS), Development Worksheet Remarks (MCS),
and on the SSA-831-U3 (Disability Determination and Transmittal), Item 2, DDS Code
•
Annotate the SSA-831, Item 11, Remarks: Dependent RR Annuitant for CDB or DWB cases
•
For non-MCS or non-MSSICS cases, use the SSA-831 to transmit case per DI 11050.060B.
•
Create the MDF for ALL non-EDCS cases.
–
Annotate the upper right-hand corner of the MDF RR.
–
Assemble the folder, complete all screens, then forward folder to:
DCR,
Branch 2A
P.O. BOX 87755 3RD FLOOR
Chicago IL. 60680-0955
Do Not Open in Mailroom
