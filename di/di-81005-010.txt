DI 81005.010 Office Code Field
Many eView screens display an office code field that identifies the office with case
jurisdiction. Users can view the office code field by placing the cursor on the field
allowing the user to view details about the office including the:
•
Office code;
•
Office type;
•
Office name;
•
Address; and
•
Administrative telephone number.
On some screens, the office code is a link that when selected displays detailed office
information. Other screens contain an “Office Description” link next to the office
code that displays the same information when selecting the link.
