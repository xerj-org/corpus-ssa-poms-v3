C. Reconsideration Actions
•
Reconsideration disability actions will be received for manual processing in the same
manner as initial claims. See DI 80830.050B.1.
•
EF folder documentation requirements for reconsideration actions are the same as those
for initial claims. See DI 80830.050B.2.
