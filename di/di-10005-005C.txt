C. Create the disability folder
1. Certified Electronic Folder (CEF) cases
Create the CEF by establishing the disability case in the Electronic Disability Collect
System (EDCS). If the claimant completed the disability report online, the Internet
Disability Report (IDR) propagates in EDCS, otherwise, create the appropriate disability
form(s) via EDCS.
NOTE: Complete an SSA-3369, Work History Report and an SSA-3373, Function Report - Adult,
when the claimant is unavailable or would be difficult to contact at a later time
(e.g., due to homelessness).

2. Paper Modular Disability Folder (MDF)
If the case cannot be established in EDCS and processed electronically, create a paper
MDF to house the case.
