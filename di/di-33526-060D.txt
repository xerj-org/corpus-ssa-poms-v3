D. Reminders for choosing an impairment code for mental disorders
•
Do not use impairment code 3150 if the child is over age three at the time of adjudication.
•
Do not use impairment code 3195 or 3152 if the allowance is based on meeting or equaling 12.05 or 112.05. If the allowance
is based on meeting or equaling an intellectual disorder, use code 3180.
•
Impairment codes 3030 and 3040 should only be the primary impairment code when the case is a denial because drug
addiction or alcoholism (DAA)
is
material. When the case is an allowance because DAA is not
material, enter the mental or physical impairment found to be disabling, absent the effects
of DAA, as the primary diagnosis, and enter impairment code 3030 or 3040, as appropriate, as the secondary diagnosis.
