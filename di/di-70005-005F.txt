F. List of standardized claim file forms
The following is a partial numerical list of standardized Title II and Title XVI claim
file forms and includes the color-coded section of the MDF where you should file the
form.
An asterisk (*) identifies Title XVI forms. For a Title XVI only disability claim,
file these forms in the MDF. For a concurrent claim, these forms will remain in a
separate two-part brown folder housing the Title XVI non-medical material.
