B. Routing Closed eCDRs
Always send the paper CPD folder to the same office to which you transferred the eCDR
CEF. Include messages as to what action is necessary, if any, for both the paper and
electronic folder. Route cases based on decision (DEC) codes as follows (unless selected
for OQR review).
NOTE: Do not remove “eCDR Paper CPD Folder Flag” from any paper CPD folder.
1. Continuance (DEC = CO)
a. No Action is Necessary
•
Use these destination codes on both NDDSS and Electronic Folder Interface (EFI):
•
Title II and concurrent use office code N88 (National Records Center [NRC] Folder
Storage)
•
Title XVI only use L0(zero)E (NRC Folder Storage)
b. Action is Necessary (i.e., Work Issues, Payee Issues, Capability, Reopenings)
•
Add a message to the CEF via the case processing system describing the necessary action;
and
•
Route to the FO
NOTE: If there is a question whether or not any action is necessary, the best procedure
is to route the case to the FO so they can determine the proper course of action and
the proper routing procedure.
2. Cessation (DEC = CE)
Route both Title II and Title XVI to the FO.
