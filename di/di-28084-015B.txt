B. Title II and Title XVI cessation basis codes (Item 11 of SSA-832 and SSA-833)
1. Entering the cessation basis code
Enter the following information:
•
the appropriate reason for cessation code from the lists in this section;
•
only one code even if more than one code could apply. Use the code that best describes
the basis for the determination;
•
for Title II cases, if a Group 1 exception applies, use codes 02, 03, 04, or 05; and
•
for Title XVI cases, if a Group 1 exception applies, use codes 51, 52, 53, or 54 for
adults, or codes 91 or 92 for children.
2. One-position cessation codes for Title II CDR
NOTE: When the field office (FO) or Office of Disability Operations (ODO)/ Program Service
Center (PSC) has made a determination and is manually processing the SSA-833, enter
both (a one-position and two-position code) with the SSA-4648-U3 (Title II/Title XVI
Disability Claims Control and Determination Input). Choose the most specific two-position
code and then convert it to the more general one-position code. If more than one code
applies for either of the two types of cessation codes, choose only one code for each
type:
