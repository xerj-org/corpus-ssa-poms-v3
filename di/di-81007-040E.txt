E. iCAL
CAL is an effort to expedite disability determinations for claimants whose medical
conditions invariably result in allowances. The i3820 has one feature related to the
Compassionate Allowances (CAL) initiative, iCAL.
The i3820 does not collect a list of the child’s impairments in the same manner as
the i3368. Instead, the IU enters a prose narrative into a free-form text box that
allows the user to enter up to 1000 characters. The iCAL feature in the i3820 screens
IU’s description of the child’s medical conditions for the word “cancer.” If the i3820
finds the word “cancer” in the text, it displays a pop-up message on the IU’s screen.
The message instructs the IU to specify the type of cancer and stage of the cancer,
if not already shown.
