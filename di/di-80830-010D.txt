D. Accessing the EF
EF information can be accessed as follows:
•
Use the eView desktop icon, or
•
Enter the eView website here, or
•
Use interfaces from the case processing systems that link directly to the eView application
(e.g., DDS legacy systems, Disability Case and Review System (DICARS), Case Processing
and Management System (CPMS), etc.).
