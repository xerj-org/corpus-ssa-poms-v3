DI 80630.001 Processing Center (PC) Procedures
Overview
Until a seamless interface has been completed, the PC will continue to operate using paper
folders and the paperless process.
Future electronic folder (EF) system enhancements will eventually provide an interface
between the PC control systems and the EF. In addition to using eView to view, print
and/or copy structured and unstructured folder documentation, the PC staff will have
the ability to add documents to the EF data base, send alerts, messages, etc. via
an application programming interface.
Beginning January 2004, PCs have the ability to create barcodes for documents. However, at this time PCs should not create bar codes.
