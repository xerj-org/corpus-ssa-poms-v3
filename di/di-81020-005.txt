DI 81020.005 Electronic Folder Interface (EFI) Download
The Electronic Disability Collect System (EDCS) creates an Electronic Folder Interface
(EFI) Download for each claim which can be used to receipt each claim. The download
contains basic data about the claimant (e.g., SSN, name, address, date of birth, claim
type and level) as well as detailed data from the disability report form(s). An EDCS
Routing Form is automatically generated at case transfer to the Disability Determination
Services (DDS). The DDS can expect to have an EFI download on all claims listed on
the EDCS Routing Form.
