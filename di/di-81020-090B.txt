B. Adding a Message
When creating a message, the user has the option to enter an expiration date or to
leave it blank. Multiple messages may exist in a CEF and each message may contain
up to 1,000 characters. To create a message:
•
The Message Information Screen is used to add a message to the case.
•
On the Message Information Screen, you will be able to add the message description
and the message expiration date, if appropriate.
•
If the office creating the message does not have jurisdiction, the office with jurisdiction
will be notified of the presence of a new message only if that office has two-way
update capabilities.
