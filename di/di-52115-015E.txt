E. Processing post entitlement cases involving BL Part C
When proof is received, the FOs and PCs takes the following post entitlement actions:
•
Verify the validity of the documents. If necessary, contact DOL to confirm any questionable
data. Follow the guidelines shown in DI 52115.015C. in this section.
•
Offset the Part C BLB amount plus any separate amounts to auxiliaries. For instructions,
see DI 52165.000 - Interactive Computations Facility (ICF) for Workers’ Compensation/Public Disability.
•
Update the changes to the BL Part C via ICF WC, coding the offset type code as “BL”.
For instructions, see DI 52165.000 - Interactive Computations Facility (ICF) for Workers’ Compensation/Public Disability.
