G. Example of coding bank data for Curacao
The customer provides us with a signup form for Curacao containing the account number:
1234567890123
1. Derive the RTN
Enter the information for the RTN.
•
Code the RTN of 730000024
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
Code the DAN for Curacao
•

•
