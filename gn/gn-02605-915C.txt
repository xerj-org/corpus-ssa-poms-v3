C. Description of the Canadian Postal Codes
The Canadian postal system uses postal codes consisting of six alphabetical (A) and
numerical (N) characters as follows:
•
There is always a space between the first three characters and the last three characters.
•
ANA NAN where “A” represents a letter of the alphabet and “N” represents a number.
Locate Canadian postal codes by street address, locality, and province from the Canadian
postal system website via the UPU website. Make every effort to locate the correct
postal code for all awards and changes of address. However, do not show a code if
you cannot locate the correct one. The postal code is the only entry on the last line
of the address, followed by the consular code on the same line. Example:
First and Last Name
Number and Street
Town/City Province Canada
ANA NAN
