SSA Program Operations Manual System (POMS) - GN 02401.912 - Forwarding the Handwriting Analysis Package to the Questioned Documents Branch (QDB) for Review
Effective Dates: 01/15/2025 - Present | TN 52 (01-25)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0202401912 (fetched 2026-10-04)

A. Background
Request a handwriting analysis for a check older than 12 months old only if the beneficiary,
recipient, or representative payee did not file a timely nonreceipt, and the missing
payment is a part of an overpayment on the record.
NOTE: Review the responses to the questions on the CIPS letter to make sure the letter
is complete.
