G. Example of coding Croatian bank data
The customer provides us with a signup form for Croatia containing the following information:
"HR1210010051863000160".
•
The first 2 characters of a Croatian IBAN “HR,” represent the International Organization
for Standardization (ISO) country code
•
The third and fourth characters of the IBAN are the IBAN check digits. The technicians
should never code these to the MBR.
•
mThe next 7 characters of the IBAN represent the 7-digit bank code.
•
The last 10 characters of the IBAN represent the 10-digit account number.
1. Derive the RTN
The technician enters the information for the RTN
•
prefix of “66” (the multi-country prefix for Croatia),
•
first 6 digits of the 7-digit bank code “100100”,
•
1-digit check digit code (i.e., 8) (obtained from the Title II Interactive Comps from
the Main Menus 07/Sub Menu 16), and
•
type of account as a “C” for checking or an “S” for savings. If no indicated account
type, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN
•
“Q” (for Croatia),
•
last digits of the bank code“5”, and
•
10-digit Customer Account Number “1863000160”.
3. Obtain the following information
•
RTN: 661001008
•
Checking
•
DAN: Q51863000160

•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 661001008 ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: Q51863000160
•
CANCEL DIRECT DEPOSIT (Y):
•

b. The MBR reflects the following information
•
