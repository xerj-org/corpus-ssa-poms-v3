GN 01712.015 Procedure for Reviewing and Completing Claims taken by the FSP
When you receive a claim file from the FSP, check the file for the forms listed in
GN 01712.010. If any are missing, contact the FSP. If the Norwegian coverage record is not attached,
request it from the FFU. Check the file for a U.S. totalization earnings record. If
there is no totalization earnings record in file, request it by following the instructions
in GN 01704.570.
