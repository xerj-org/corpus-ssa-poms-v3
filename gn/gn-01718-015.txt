GN 01718.015 How to Review and Complete Claims Taken by the FSP - Procedure
When you receive a claim file from the FSP, check the file for the forms listed in
GN 01718.010. Request the FSP to obtain any missing forms.
Use the following guidelines to control receipt of the Swedish earnings record (Form
029):
If the FSP Requested a Form 029....
Then....
More than 90 days ago
•
Prepare an
SSA-2960-U3-SW status request.
•
Show date of FSP request in IV.E.
•
Diary for 90 days.
Less than 90 days ago
Diary for 90 days from date of FSP request.
If the FSP did not
request a Form 029....
Then....
•
Prepare an
SSA-2960-U3-SW requesting a Swedish coverage record.
•
Diary for 90 days.
Check the file for a U.S. totalization earnings record. If there is no totalization
earnings record in file, request it. (See
GN 01704.570)
