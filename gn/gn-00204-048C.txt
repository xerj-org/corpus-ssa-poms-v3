C. General procedure for processing all MOEL T2R exceptions
When processing an exception for any MOEL code, consider any new and material evidence
and follow these steps:
1.
Identify the current MOEL option code (see GN 00204.041).
2.
Review the MOE CONFIRM CODE value on the MBR (see SM 00606.095B.1.).
3.
Apply the annual earnings test (AET) (see RS 02501.021).
4.
Charge off the excess earnings per RS 02501.095B using the current MOE and the EPDOE.
5.
Make a MOEL determination.
