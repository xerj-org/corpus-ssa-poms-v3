SSA Program Operations Manual System (POMS) - GN 00210.020 - Processing Instructions for Title II Same-Sex Relationship Claims, Reconsiderations, and Hearing Requests
Effective Dates: 10/05/2017 - Present | TN 69 (04-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0200210020 (fetched 2026-10-04)

A. Processing Title II claims involving the determination of a same-sex marital relationship
or NMLR
Develop all initial claim applications, appeals, and post-eligibility actions in MCS.
Enter the code on the development worksheet (DW01) that corresponds to the type of
same-sex relationship alleged by the claimant at the time of application.
Enter the first four positions of the unit type code as listed:
•
Marriage (including common law), enter code 626M
•
Civil union, enter code 626C
•
Domestic partnership, enter code 626D
•
Reciprocal beneficiary, enter code 626R
•
Other same-sex relationship, enter code 626O
Document all pertinent information regarding the claim on the Report of Contact (RPOC)
screen.
Add Listing Code 626 on the Decision Input (DECI) screen.
IMPORTANT: Retain the unit code, regardless of the determination or changes made in the adjudicative
level of the case.
