GN 00301.313 The Inter-Relationship of the Non-Disability Repository for Evidentiary Documents
(NDRed) Application as it Relates to the Non Disability Repository (NDR) and the Claims
File User Interface (CFUI)
•
The NDRed application in the Evidence Portal will be used to obtain sufficient information
about an artifact and to associate that artifact with the correct claim filing and
prepare a Document Manager Architecture (DMA) barcode FAX document.
•
The DMA Fax barcode and copy of the artifact will be faxed into the Non Disability
Repository (NDR) that is contained in a section of DMA.
•
CFUI will be used in the Evidence Portal (see SM 08001.000) to view the artifact after
it has been stored in the NDR.
