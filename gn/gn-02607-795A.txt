A. PROCEDURE - INMATE STATUS CODES ON 3BOP PUPS ALERTS EFFECTIVE 04/04/2002
INMATE STATUS CODE
BOP INMATE STATUS CODE DESCRIPTION
SSA GENERAL DESCRIPTION OF INMATE STATUS CODE
Y
CONVICTED, SENTENCED TO MORE THAN 12 MONTHS.
Convicted--Individual has been convicted of a crime (e.g., felony or misdemeanor) and is confined
to a correctional institution.
C
CONFINED BUT NOT CONVICTED
Confined but not convicted--Individual is confined in a correctional institution but has not been convicted
of a crime.
P
PAROLE VIOLATOR
Parole or probation violator--Individual has violated parole or probation. An official determination has been made
to return the individual to confinement at a correctional institution.
