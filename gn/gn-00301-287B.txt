SSA Program Operations Manual System (POMS) - GN 00301.287 - How Evidence is Recorded on EVID and Report of Contact page in the Consolidated Claims Experience (CCE) in PE Situations
Effective Dates: 06/15/2023 - Present | TN 86 (06-23)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0200301287 (fetched 2026-10-04)

B. Report of Contact page in CCE
1. Locking the Report of Contact page in CCE
To store the evidence/documents in PE situations once they are established on the
Report of Contact page, the screen must be locked. See MS 08122.010.
2. Same Document Used for Eligibility for More Than One Claimant
Use the same Report of Contact page for all claimants. Identify claimants by name
and BOAN.
3. Same Document for Multiple Issues
Use the same Report of Contact page to identify all issues that are to be proven by
a single document.
4. Multiple Documents for the Same Issue
Record multiple documents for the same issue on the same Report of Contact page.
5. Multiple Documents and Multiple Issues
Use one Report of Contact page for multiple pieces of evidence involving different
issues.
