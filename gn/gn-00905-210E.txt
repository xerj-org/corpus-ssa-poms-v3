E. Procedure beneficiary address
To ensure that all notices, including those which are computer-generated, are routed
through the U.S. Embassy in Bern, give all beneficiaries in Iran the following address:
c/o American Embassy, Bern
Department of State
Washington, D.C. 20520 833
Show the “20520” ZIP code as the last item of the address. Do not input it as the ZIP code.
Input the consular code for Iran (833) as the ZIP code.
Use the geographic code for Iran (55270).
Flag the left side of the folder with the beneficiary's residence or mailing address.
