B. Death Notification Entry (DNE) process
SSA generates a non-monetary entry called a Death Notification Entry (DNE) as soon
as the verified death is posted to the Title II or Title XVI record. A reclamation
request then orbits 20 days for Title II, or 30 days for Title XVI, awaiting possible
payment returns from the FI. For more information on DNEs, see GN 02408.605.
NOTE: The term "orbit" is used to describe an item that sits on a static file that is reviewed
daily by SSA systems to determine if an action is needed.
