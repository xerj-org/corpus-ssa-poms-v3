4. Remarks:
If the year of the event is unknown, the fee is an additional $1.00 for each calendar
year to be searched. No fee is required for a birth record if the request is from
a New Jersey Social Security office and shows that the birth certificate is needed
for Social Security purposes. For divorce records for 1980 and later write to the
Clerk, Superior Court, Chancery Division, ZIP Code 08625-0967. For divorce records
prior to 1980, write to Superior Court, Records Information Center, CN 067, Trenton,
N.J. 08625-0967. Phone requests cannot be made for divorce records. Divorce records
cost $10.00 for the first 5 pages,$.75 each for pages 6-10 and $.50 each for pages
11-20.
Requests for records, using a bank card can be made by calling (609)633-2860. There
is a $5.00 surcharge for this service.
Can FO verify, certify or obtain free copy of birth/death record? Yes
