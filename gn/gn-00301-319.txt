GN 00301.319 The Purpose of Non Disability Repository Application (NDRed)
NDRed is a web-based Application program that allows users to fax a paper document
into the NDR. The purpose of the NDRed Repository Application is to allow users to
make a document "fax ready" by selecting an appropriate document type, and associating
the document with the appropriate claim filing record.
