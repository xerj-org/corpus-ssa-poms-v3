C. Procedure - documentation
1. Modernized Claim System (MCS) applications
Annotate the MCS Development Worksheet (DWO1) screen with the SSA-L566-U2 issue date
to establish a systems record that the applicant was advised of the protective filing
closeout period. Store the SSA-L566-U2 notice in the Online Retrieval System (ORS).
2. Non-MCS applications
Include the file copy of the SSA-L566-U2 in the claims folder as documentation of
the evidence requested and the protective filing closeout date. Once the application
is effectuated, store a copy of the mailed SSA-L566-U2 in Evidence Portal (EP). See
GN 01010.001 for the definitions of effectuate and adjudicate.
NOTE: If the valid application is never received, store all protective filing documentation
in EP, including the SSA-L566-U2.
