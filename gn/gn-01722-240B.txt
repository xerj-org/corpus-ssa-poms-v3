SSA Program Operations Manual System (POMS) - GN 01722.240 - How OIO Processes Spanish Agency Requests for Information Submitted on Form E/USA 3
Effective Dates: 01/13/1994 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201722240 (fetched 2026-10-04)

B. Procedure
Before releasing information to a Spanish agency, make certain that one of the following
conditions is met:
•
the Privacy Act authorization block on form E/USA 3 is checked “yes,”
•
the claimant's signed authorization to release information to the Spanish agency is
submitted with the request, or
•
there is a totalization application in file.
If none of these conditions is met, do not release information to the Spanish agency.
Return the request and ask the agency to resubmit it with the proper authorization.
