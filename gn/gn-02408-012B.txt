B. Process for manual E-stop inputs
1. Title II PC processing
When exceptions prevent the system from generating automated E-stops, the PC inputs
E-stops for all months after death via RSDHI using PESP (MSOM RSDHI 002.005) input
screens or by using the SSA-4510 Stop Payment Request Input Form (MSOM INTRANETMAMPSCDI
004.003) screen. For PC processing instructions, see SM 00609.001B.2.
Manually input PMA amounts that are not due AND are reclaimable in the SPA O/P field
on the MBR
2. Title XVI FO processing
When exceptions prevent the system from generating automated E-stops, the FO inputs
E-stops for all months after death via the UPST screen in MSSICS by selecting stop-payment
reason 1 = Death. See MSOM BUSSR 003.017.
