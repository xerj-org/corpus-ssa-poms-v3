SSA Program Operations Manual System (POMS) - GN 00502.120 - Role of the Representative Payee System (eRPS) in Investigating Payee Applicants
Effective Dates: 04/15/2016 - Present | TN 43 (04-16)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0200502120 (fetched 2026-10-04)

B. Definitions
1. Electronic Representative Payee System (eRPS)
The eRPS is the integrated system used to process payee applications, query payee
performance, process mass change actions (including change of address of organizational
payees), document misuse allegations, document any significant information about the
payee (Make Note screen), and document reasons for payee appointment or non-appointment
(Selection Notes screen).
2. Master Representative Payee File
The Master Representative Payee File is a part of the eRPS that stores the data about
each representative payee and beneficiary in representative payment.
