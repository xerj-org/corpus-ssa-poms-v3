G. Example of coding Republic of Congo direct deposit
The customer provides us with a signup form for Republic of Congo containing the account
number: “12345678901122334455667.”
1. Derive the RTN
The technician enters the information for the RTN.
•
Code the RTN of 750000020
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN.
•
Start with the country code of “A” designated for Republic of Congo; and
•
Code 16 digits of the 23-digit account number “1234567890112233”
3. Obtain the following information
•
RTN: 750000020
•
Checking
•
DAN: A1234567890112233
a. POS reflects the direct deposit information
•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 750000020 ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: A1234567890112233
•
CANCEL DIRECT DEPOSIT (Y):
•
DIRECT EXPRESS (Y):
b. The MBR reflects the following information
•
RTN- 750000020
•
DAN- CA1234567890112233
