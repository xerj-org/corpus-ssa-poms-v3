F. Treasury action when claimant denies receiving a claims package
The claims package can contain either the same address found on the check in question
or the address used on SSA's nonreceipt input. If claimant denies receiving the claims
package, follow instructions in GN 02406.220 concerning failure to receive form FS-1133 claims package.
