B. Accessing the client database
Access the client database via the Shared Process Menu. After taking suspense actions
(or deferring the sanction), enter the sanctions information onto the Administrative
Sanctions (SPAS) screen following the instructions in MS 01701.005. The SPAS screen
collects data about imposed or deferred administrative sanctions.
For more information on how to access the client database, see MS 01701.002.
