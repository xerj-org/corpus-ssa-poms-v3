C. The FTD Application in SSI claims
The FTD application is a query feature available on the SSI Claims Actions page within
the Consolidated Claims Experience (CCE) system. For more information on using the
FTD application for SSI purposes, see SI 00501.409.
Additionally, the FTD User Guide provides step-by-step instructions on how to access and use the FTD application and
is available via a user guide link in the upper right-hand corner of the FTD application.
