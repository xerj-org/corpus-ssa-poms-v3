D. Multiple name discrepancies
If more than one document is submitted which has a name discrepancy (e.g., the claimant
has used aliases), obtain a written statement from the claimant to explain the various
names. If you are still not convinced that a particular document pertains to the claimant, take one or more of
the actions described in C. above.
However, do not resolve a name discrepancy if it appears on a document that would not, even if corroborated,
influence your determination.
