SSA Program Operations Manual System (POMS) - GN 01722.005 - How OIO Reviews and Completes Claims Taken by a Field Office (FO)
Effective Dates: 02/21/1996 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201722005 (fetched 2026-10-04)

A. Procedure
Follow these steps for reviewing claims in a totalization module:
Step
Action
1
Review the file for the required applications and evidence listed in GN 01721.205 - GN 01721.215. (See GN 01704.570 for additional instructions for developing and evaluating evidence).
​
2
•
Check the file for proof of lag earnings if lag wages or lag self-employment are alleged.
(Proof of lag earnings is required through the quarter of retirement, disability or
death).
•
If additional proof is needed, request the FO to obtain it.
3
•
Check the file for a U.S. totalization earnings record which can be sent to the Spanish
agency.
•
If there is no totalization earnings record in file, request it from OCRO following
the instructions in GN 01704.570.
4
Send the claimant the appropriate Spanish application form following the instructions
in GN 01722.006.
5
When all of the material required above is in file, refer to the guidelines in GN 01722.205 for preparing a claims package for the Spanish agency.
