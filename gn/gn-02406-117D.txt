D. Process - Courtesy Disbursement/Replacement Checks
Courtesy disbursement checks should be received within 10 days after input of the
request to make payment before determining status of the missing check. (An ‘A-stop’
is for a mass loss, which is when all of the checks in a specific location are undeliverable
because they are permanently lost, stolen, or otherwise unavailable for delivery,
see GN 02406.700. A ‘B-stop’ is for nonreceipt of an unendorsed check, regardless of whether it is
a current month check, prior month check, or PMA, see GN 02406.125). If SSA requests Treasury to determine the status of the original check before making
payment (a ‘C-stop’ – see GN 02406.150), a replacement check, if due, should be received within 5 weeks of the original
input of nonreceipt as long as the original check has not been cashed. If the original
check was cashed then a forgery analysis must be done before a settlement check can
be issued.
