B. Description of form SSA-2960-U3-FI
The form consists of three pages.
•
Page 1 (Blue file copy) is written in English and is used for folder documentation.
•
Page 2 (White First Request Copy) is written in Finnish and is the initial copy sent
to the Finnish agency.
•
Page 3 (Yellow follow-up copy) is written in Finnish and is used as a follow-up request
when necessary.
