SSA Program Operations Manual System (POMS) - GN 01724.006 - Controlling Requests for Medical Report Forms
Effective Dates: 03/21/2017 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201724006 (fetched 2026-10-04)

B. Procedure
Follow this procedure when controlling requests for medical report forms.
1. Initial
Place a copy of the letter to the claimant in the totalization electronic folder and
diary for 60 days.
2. First Follow-up Action
Did you receive a response after 60 days?
•
If yes, prepare a claim package for France which includes the Medical Report Form.
•
If no, send a second letter, Medical Report Form and preaddressed return envelope.
Diary for an additional 30 days.
3. Second Follow-up Action
Did you receive a response after the additional 30 day diary?
•
If yes, prepare a claim package for France which includes the Medical Report Form.
•
If no, prepare a claims package for France which does not include the Medical Report
Form. Explain on Form SSA-e2960-U3-FR (USA/France Liaison Form) that the Medical Report
was requested twice but not returned.
