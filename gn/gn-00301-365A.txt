A. Procedure - General - Foreign Language Documents for Translation
1. Selecting translator
Use the priority list in GN 00301.330.
2. Multilingual documents
If a document is written in more than one language (none of which is English), have
it translated in the language of the country in which it was issued, if this will
not unduly delay processing the claim. Follow this selection process when choosing
either Social Security Administration (SSA) or non-SSA translators.
