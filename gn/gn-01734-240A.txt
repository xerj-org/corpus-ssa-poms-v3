SSA Program Operations Manual System (POMS) - GN 01734.240 - How OIO Processes Luxembourg Agency Requests for Information Submitted on Form LUX/USA 3
Effective Dates: 02/17/1994 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201734240 (fetched 2026-10-04)

A. Procedure
Before releasing information from SSA records, make certain that:
•
the information is needed to process a claim under the agreement, or
•
the claimant has submitted a signed authorization which permits the release of information
to the Luxembourg agency.
Check the file for one of the following conditions:
•
the Privacy Act authorization block on form LUX/USA 3 is checked “yes,”
•
the claimant's signed authorization to release information to the Luxembourg agency
is submitted with the request, or
•
there is a totalization application in file.
If none of these conditions is met, do not release information to the Luxembourg agency.
Return the request and ask the agency to resubmit it with the proper authorization.
