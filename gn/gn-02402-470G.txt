G. Example of coding Guinea direct deposit
The customer provides us with a signup form for Guinea containing the account number:
“123456789011223344.”
1. Derive the RTN
The technician enters the information for the RTN.
•
Code the RTN of 730003267
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN.
•
Start with the country code of “E” designated for Guinea; and
•
Code 16 digits of the 18-digit account number “1234567890112233”
3. Obtain the following information:
•
RTN: 730003267
•
Checking
•
DAN: E1234567890112233
a. POS reflects the direct deposit information
•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 730003267 ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: E1234567890112233
•
CANCEL DIRECT DEPOSIT (Y):
•
DIRECT EXPRESS (Y):
b. The MBR reflects the following information
•
RTN- 730003267
•
DAN- CE1234567890112233
