B. Processing Center Action Required
If an action requires Processing Center action to clear, the item should be placed
in NDRed using the EP or the eDIB claim filing record. The item should also be faxed
into the Paperless Processing System using existing procedures.
NOTE: No documents should be faxed or sent to the Processing Centers “to be filed.” The
document, must be faxed into the Non-Disability Repository in the EP or the eDIB claim
filing record.
