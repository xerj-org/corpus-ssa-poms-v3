D. Timeframes and methods of transmission of State data exchange applications
We process State data exchange requests through applications that either handle the
requests through a batch process or a real-time process. When processing the data
exchange request through our batch process, we receive the request and return a response
within 48 hours. When processing the data exchange request through our real-time process,
we will respond to the request within seconds.
NOTE: Data exchange partners must submit their data exchange request through the method
of transmission that they and SSA agreed upon in the data exchange agreement. For
example, if the agreement outlines a batch submission, the data exchange partner cannot
submit the data exchange request as a real-time request or vice versa.
