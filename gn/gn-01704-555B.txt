B. Completing the Items on the Form SSA-4766-U3
1.
Number Holder—Always enter the last name, first name and middle initial of the number
holder.
2.
Claim Number—Enter the NH's SSN and the claim symbol for the beneficiary to whom the
SSA-4766-U3 refers. Show “Alpha” when appropriate.
3.
Date—Enter the current date.
4.
Module—Enter module number.
5.
To—Enter appropriate servicing DO. This can usually be determined by the claimant's
address, the DO code on the application or other material in folder, the Service Area
Directory or the State and County Code Book.
6.
DO Code—Enter code for DO indicated.
7.
Furnish Status Report on Request Dated—Complete only on followup requests.
8.
Diary—Prepare a Form SSA-382-U2.
9.
From—Always circle “INTPSC.”
10.
TOE Code—Enter the appropriate TOE; 190 for concurrent RSDI and totalization claims;
320 for totalization claims from RSDI beneficiaries; and 430 for foreign totalization
benefits only. (See GN 01704.580 for additional TOE codes.)
11.
Evidence Code—Enter the appropriate code.
a.
21 R for applications;
b.
11 R for lag earnings;
c.
78 R for all other.
12.
Award—Do not complete.
13.
Name of Beneficiary—Enter name(s) and address(es) of claimant(s).
14.
Telephone Number—Enter telephone number (including area code) of claimant(s).
15.
Please secure. . .—Indicate whatever evidence, proofs, application, etc. are needed.
16.
Remarks—Indicate “Totalization Claim Pending” when applicable, and show any other remarks which are appropriate.
17.
“Please return attachments” should be checked if appropriate.
18.
Manual References—Indicate the appropriate references. (Use only references distributed
to DOs.)
19.
Director of Operations—Line through, sign your name and shown “liaison clerk.”
