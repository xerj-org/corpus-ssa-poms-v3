SSA Program Operations Manual System (POMS) - GN 01750.005 - How OIO Modules Review Claims under the U.S.-Czech Republic Totalization Agreement
Effective Dates: 08/20/2020 - Present | TN 2 (08-20)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201750005 (fetched 2026-10-04)

A. Procedure
Follow these steps for reviewing claims under the U.S / Czech Republic Totalization
agreement:
1.
Review the file for the required applications and evidence listed in GN 01750.205 - GN 01750.220.
2.
If the person is filing for Czech benefits and the “Claim for A Pension from the Czech
Republic” (CZ/USA202) is not in file, mail the appropriate application form with instructions
to mail the completed form directly to the Czech Republic agency, Ceska Sprava Socialniho
Zabezpeceni (CSSZ) below:.
Ceska Sprava Socialniho Zabezpeceni (CSSZ)
Krizova 25, 225 08 Praha 5
CZECH REPUBLIC
NOTE: Print the Claim for a Pension from CSSZ (CZ/USA 202) from the OCO Totalization Resource Kit.
3.
Check the file for a U.S. totalization earnings record that can be sent to CSSZ. If
one is not in file, request an ICERS record following the instructions in MSOM ICERS
001.001 and MSOM ICERS 001.004 for inclusion in the package to CSSZ.
4.
Confirm that all available medical evidence has been included if the claim is for
disability benefits.
5.
When all required material is in file, refer to the guidelines in GN 01750.205 - GN 01750.210 for preparing a claims package for CSSZ.
