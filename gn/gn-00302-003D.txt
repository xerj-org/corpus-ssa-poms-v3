D. Action required on advance determinations
The remark “CK CORRES” in the OCRO Conditions data group of the free-form E /R indicates that there is correspondence
of some type on file in OCRO for the worker, which would include any DB information
which had been previously submitted under this procedure. When this remark appears
on the E/R, but no evidence is forwarded with the E/R, ask the worker if he/she had
previously submitted evidence to SSA. If so, request the file by telephone from the
Office of Central Records Operations, Metro West Building, or ask the claimant to
resubmit the evidence.
If evidence of higher probative value is still needed, SSA can pay for a census record
search or other necessary documentation.
