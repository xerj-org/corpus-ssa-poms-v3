G. Example of coding direct deposit for Palau
The customer provides us with a signup form for Palau containing the account number:
“12345678901122334455667788990.”
1. Derive the RTN
The technician enters the information for the RTN.
•
Code the RTN of 720000092
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN:
•
Start with the country code of “G” designated for Palau; and
•
Code 16 digits of the 29-digit account number “1234567890112233”
3. Obtain the following information:
•
RTN: 720000092
•
Checking
•
DAN: G1234567890112233
a. POS reflects the direct deposit information
•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 720000092 ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: G1234567890112233
•
CANCEL DIRECT DEPOSIT (Y):
•
DIRECT EXPRESS (Y):
b. The MBR reflects the following information
•
RTN- 720000092
•
DAN- CG1234567890112233
