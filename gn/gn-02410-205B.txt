SSA Program Operations Manual System (POMS) - GN 02410.205 - Service of a Garnishment Order
Effective Dates: 01/20/2010 - Present | TN 14 (06-03)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0202410205 (fetched 2026-10-04)

B. PROCEDURE
1. Improper Method of Service
If a garnishment order is delivered by a method not in accordance with the law of
the state in which it is issued, return it to the court using the notice in NL 00703.726.
If the order is properly served but on an SSA component other than an FO or PC (e.g.,
a Regional GC), do not return the order. Send it to the nearest FO for processing.
2. Incorrect Party Named
If a garnishment order is served on SSA, but SSA is not expressly named as the “garnishee”,
“employer”, “income payer”, etc., accept the order and process per GN 02410.210. However, if the order specifically names someone other than SSA (e.g., General Electric),
return it to the issuing entity using the notice in NL 00703.726.
3. Service on A PC
If a garnishment order is served on a PC, see GN 02410.210.
