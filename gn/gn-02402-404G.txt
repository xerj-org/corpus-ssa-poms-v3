G. Example of coding Ecuador direct deposit
The customer provides us with a signup form for Ecuador with the account number: "12345678901122334455667788990"
1. Derive the RTN
The technician enters the information for the RTN.
•
Code RTN of 700000041
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN.
•
Start with country code “V” designated for Ecuador; and
•
Code16 digits of the 20-digit account number: “1234567890112233”
3. Obtain the following information
•
RTN: 700000041
•
Checking
•
DAN: V1234567890112233
a. POS reflects the direct deposit information
•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 700000041
•
ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: V1234567890112233
•
CANCEL DIRECT DEPOSIT (Y):
•
DIRECT EXPRESS (Y):
b. The MBR reflects the following information
•
RTN- 700000041
•
DAN- CV1234567890112233
