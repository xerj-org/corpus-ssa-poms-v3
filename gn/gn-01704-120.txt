GN 01704.120 Totalization Status Code (TSC)
The MBR (online and offline) and all computer output displays a two-position TSC which
describes, in general, the status of payments under totalization. When reviewing form
SSA-2417 B, verify that the correct TSC code is shown. The following is a description
of the applicable TSC codes and an explanation of when they are shown.
