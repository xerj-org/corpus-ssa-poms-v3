C. Return of conserved funds to the estate of the deceased beneficiary
Conserved funds do not constitute an underpayment. However, we will return those funds
to the estate of a deceased beneficiary. For more information, see GN 02301.001B. If the beneficiary dies and there is a representative payee who is permitted to continue
to administer conserved benefits, see GN 00603.100B.2.
NOTE: If we receive conserved funds for a deceased beneficiary, do not return these funds
to the former payee. For more information, see GN 00603.055B.5.
