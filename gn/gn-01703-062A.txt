A. Introduction
Several liaison forms contain check blocks that may be used to indicate the type of
U.S. benefit for which the claimant wants to file. If one of these blocks is checked,
DIO and FSPs use the following instructions to determine if there is a claims lead
and if an informal denial notice is necessary.
