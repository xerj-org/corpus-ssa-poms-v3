SSA Program Operations Manual System (POMS) - GN 02401.911 - Preparing the Handwriting Analysis Package for Treasury’s Questioned Documents Branch (QDB) Review
Effective Dates: 01/15/2025 - Present | TN 52 (01-25)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0202401911 (fetched 2026-10-04)

A. Background
Request a handwriting analysis for a cashed check older than 12 months old only if
the beneficiary, recipient, or representative payee did not file nonreceipt timely,
and the missing payment is a part of an overpayment on the record.
