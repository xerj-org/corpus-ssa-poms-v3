SSA Program Operations Manual System (POMS) - GN 01728.005 - How the Totalization Modules Should Review Claims Filed in a Field Office (FO) or in the Claims Development Branch (CDB)
Effective Dates: 06/04/1997 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201728005 (fetched 2026-10-04)

A. Procedure
Follow these steps for reviewing claims in a totalization module.
1. Review file
Review the file for the required applications and evidence listed in GN 01727.205 - GN 01727.215. (See GN 01704.500 for additional instructions for developing and evaluating evidence.)
2. U.S. earnings records
If there is a claim for Portuguese benefits, check the file for a U.S. earnings record.
If there is no earnings record in file, request it from OCRO, following GN 01704.570.
3. Preparing claims package
When all the material required above is available, refer to GN 01728.205 - GN 01728.210 for preparing a claims package for the Portuguese agency.
