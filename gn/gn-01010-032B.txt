B. Procedures for requesting a prior claims folder
1. Paper claims folder
•
If the prior claims material is located in the PC or the FARC and it requires review,
use the Processing Center Action Control System (PCACS) to request the folder (see
MSOM PCACS 009.011).
•
If the claims file is not readily available or the PC cannot find it, follow the instructions
in GN 01070.222.
2. Electronic folder (EF)
•
If the Retirement (RIB), survivor, and Medicare claims documentation is stored in
the Non-Disability Repository for Evidentiary Documents (NDRed), use the Evidence
Portal (EP) to review the claims information (see MS
09701.000).
•
If the Disability (DIB) claims are stored in eDIB using eView or the EP, which is
also known as the Certified Electronic Folder (CEF), use the eView web-based application
linked to the Electronic Disability Collect System (EDCS) or the EP to review the
claims information (see DI 81005.005).
3. Multiple prior claims
•
RSI - Request only the most recently stored paper folder from the PC.
•
DIB - If the Res Judicata rule was the basis for the most recent denial (e.g., technical denial code of 0S1
on the MBR per GN 03101.160 and GN 04040.010), request additional prior claims folders. If you need claims material from the most
recent substantive medical decision, request the claims folder identified as being forwarded to the FARC within two years after the Date Last Insured (DLI) for DIB.
4. Cleared or archived MCS claims
Use cleared or archived MCS screens to adjudicate the current claim if the information
displayed confirms a factor of entitlement. For more information, see GN 01010.038.
5. Query entitlement status (QENT)
In lieu of an MBR, use QENT to identify a prior filing and to obtain information on
PIAs, family maximums, and monthly benefit amounts, (see MSOM QUERIES 006.018).
CAUTION: Since QENT displays only the PIA and maximum (MAX) entries for the latest cost-of-living
allowance (COLA) and these fields update even after the NH terminates, it may be necessary
to de-convert them to the actual termination effective date. Obtain a FACT MBR if
this is the case.
6. Disability, railroad, alien and military service (DRAMS) query
a.
Use DRAMS to verify:
•
Prior periods of disability;
•
Railroad Retirement Board (RRB) data;
•
Military service (MS) data; and
•
Japanese internment data.
b.
Use DRAMS only as a lead for Non-citizen (alien) deportation dates
Note: If these dates look inaccurate or irrelevant, override the DRAMS data on MCS (see
MSOM MCSEC 001.005 MREQ and RS 02635.001). For more information about DRAMS, refer to MSOM QUERIES 005.003
