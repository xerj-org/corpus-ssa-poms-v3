SSA Program Operations Manual System (POMS) - GN 00301.288 - What Information is Needed on EVID and the Report of Contact page in the Consolidated Claims Experience (CCE) in PE Situations to Identify the Type of Evidence Submitted
Effective Dates: 08/15/2023 - Present | TN 105 (08-23)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0200301288 (fetched 2026-10-04)

B. Event Date
1. EVID
“DOCUMENT EVENT DATE” is the only mandatory date field. Since all documents should
have at least one date, enter that date in the “DOCUMENT EVENT DATE” field. “DATE
RECORDED” and “DATE ISSUED” should only be completed if they appear on the document.
When the document has a start and end date (e.g., opening and closing date on a bank
statement), always record the end date in the “DOCUMENT EVENT DATE” field. Annotate the start date in
the “COMMENTS” field. If there is no date on the document, enter the date the document
was received.
2. Report of Contact page in CCE
Always show an event date. If there is only one date, show that date as the event
date. If there is no date, enter the date the document was received. If there is a
start date and end date, record both but the end date will always be the event date.
Include the issue and recorded date, if available.
