2. Determining the Missing FID code on a 3BOP Alert
If the FID code is blank on the PUPS alert, take the following steps to locate the
SSA 6-digit FID code to annotate to the PUPS record.
STEPS
ACTION
1
Check the PURS screen on the PUPS record to locate the 3-digit BOP Facility ID Code.
2
Use the internet and go to BOP's web page at http://www.bop.gov/. Scroll down until you find "Federal Bureau of Prisons Facilities." Click on this
item.
3
Go through the list of BOP facilities on the internet site until you find the facility
with the same 3-digit code on the PUPS record. Write the facility's name and address
down for reference.
NOTE: PUPS will display the 3-digit BOP facility code on the PURS screen for SSN you are
working on.
4
Use IRCS to locate the 6-digit SSA code that corresponds to the BOP facility's name
and address. (See MSOM PRISON 002.016 for instructions on locating FIDS and RIDS on
IRCS.)
Go to the QRI2 screen in IRCS to view the SSA 6-digit FID codes and the names of the
facilities corresponding to these codes.
NOTE: You will see most of the 3-digit BOP facility codes on the QRI2 screen before the
name of the corresponding BOP correctional facility. This will assist you in finding
the BOP facility more easily.
5
Verify that the name of the BOP facility you have located is correct by querying IRCS
using the 6-digit SSA FID code you located from the QRI2 screen. (See MSOM PRISON
002.016 for instructions on locating FIDS and RIDS on IRCS.)
6
Add the correct 6-digit SSA FID code to the PUPS record when you are updating the
PUPS record with the suspension or other required action.
NOTE: Do not call the Bureau of Prisons for information about their facilities or for additional
inmate information. If you cannot locate a FID for a BOP facility, contact your Field
Operations Prisoner Coordinator (FOPC) for assistance. See GN 02607.990 for a list
of the FOPCs.
