B. Request includes name and SSN only
If the request only contains the individual’s first and last name and SSN, we may
only disclose information when we can positively locate a single record in our files
containing that exact name and SSN. If there is any uncertainty as to whether the
first and last name and SSN provided match information in our records, do not disclose
any information.
