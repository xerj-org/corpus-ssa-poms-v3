SSA Program Operations Manual System (POMS) - GN 01710.005 - How OIO Modules Should Review Claims Filed in a Field Office (FO) or in the International Benefits Office (IBO)
Effective Dates: 10/20/2014 - Present | TN 3 (06-96)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201710005 (fetched 2026-10-04)

A. Procedure
Follow these steps for reviewing claims in a totalization module.
1. Review file
Review the file for the required applications and evidence listed in GN 01709.205-GN 01709.220. (See GN 01704.500 for additional instructions for developing and evaluating evidence.)
2. U.S. earnings record
If there is a claim for Swiss disability benefits or orphans benefits based on the
record of a deceased mother, check the file for a U.S. earnings record.
If there is no earnings record in file, request it from OCRO, following GN 01704.570.
3. Special applications or referral needed
Follow GN 01710.315 to determine if a special Swiss application or referral to a Swiss office is needed.
4. Preparing claims package
When all the material required above is available refer to GN
01710.205-GN 01710.210 for preparing a claims package for the Swiss agency.
