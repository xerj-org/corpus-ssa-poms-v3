Input a B-stop by selecting “1” in 4-C on the UPMR screen – “Replace Now.” This is
the first PIN authorization for a replacement check your office wants to issue prior
to Treasury’s investigation of the status of the original payment. The system displays
the following alert:
ALERT: POSSIBLE DCN - SECOND PIN REQUIRED TO REPLACE NOW – PRESS PF1 FOR HELP
The system requires a second PIN to input the B-stop to issue an immediate
replacement. The second PIN is input on the same day as the first input to allow issuance of the
replacement payment. If this does not occur, the system drops the request for the
replacement payment overnight (no second PIN input). This results in no nonreceipt
input. See GN 02406.305E in this section for instructions to obtain second PIN authorization immediately.
