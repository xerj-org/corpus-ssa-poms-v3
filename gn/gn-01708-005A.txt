SSA Program Operations Manual System (POMS) - GN 01708.005 - How the Division of International Operations (DIO) Modules Should Review Claims Filed in a Field Office (FO) or in the International Benefits Office (IBO)
Effective Dates: 01/17/2017 - Present | TN 3 (03-97)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201708005 (fetched 2026-10-04)

A. Procedure
Follow the steps for reviewing claims in the DIO modules.
1. Review file
Review the file for the required applications and evidence listed in GN 01707.205. (See GN 01704.500 for additional instructions for developing and evaluating evidence and GN 01708.310 for claims for German disability benefits.)
2. U.S. earnings record
Check the file for a U.S. totalization earnings record (ER) which can be sent to the
German agency. If one is not in file, request it following GN 01704.570.
3. Preparing claims package
When all of the material required above is available, refer to GN 01708.205 - GN 01708.210 for preparing a claims package for the German agency.
