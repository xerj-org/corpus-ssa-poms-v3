SSA Program Operations Manual System (POMS) - GN 02406.220 - Failure to Receive Form FMS-1133 Claims Package, Forgery or Handwriting Analysis Determination Follow-up
Effective Dates: 04/13/2026 - Present | TN 134 (04-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0202406220 (fetched 2026-10-04)

D. Follow-up on a FMS-1133 claims package
All technicians will query TCIS to check the status of the FMS-1133 claims package.
•
If sent, it will take five business days to receive the claims package.
•
If five business days have elapsed and no claims package received, check TCIS for
a printable version. If neither a mailed package nor a printable version is available,
contact vHelp (vHelp analysts, only, will follow instructions in GN 02406.220E, this section).
1. TSC processing
a.
Title XVI Cases: If there is a claims package available on TCIS, the TSC technician
will send an MDW to the FO to follow-up (step 2 in this section).
b.
For Title II Cases: If there is a claims package available on TCIS, send an MDW to
the PC to follow-up (step 3 in this section).
2. FO processing
a.
If a claims package is available in TCIS or if the FO receives an MDW from the TSC,
the technician will print the package (one-time print only) and distribute it accordingly.
b.
If the technician is unable to print the package and they are unable to obtain a package
from Treasury, the FO will contact vHelp (vHelp analysts, only, will follow instructions
in GN 02406.220E, this section).
3. PC Processing
a.
If a claims package is available in TCIS or if the PC receives an MDW from the TSC
or FO, the technician will print the package (one-time print only) and distribute
it accordingly.
b.
If the technician cannot print the package, contact the Processing Center Operations
Analysis Section (PC OAS) Staff for assistance.
