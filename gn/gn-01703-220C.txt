SSA Program Operations Manual System (POMS) - GN 01703.220 - How to Process Alpha Claims Involving Totalization
Effective Dates: 05/19/2014 - Present | TN 3 (02-95)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201703220 (fetched 2026-10-04)

C. Procedure - modules
Technicians - After an alpha totalization folder is prepared, follow this procedure.
1. Benefit Earnings Technician (BET)
Benefit Earnings Technician:
a.
Request the foreign coverage record and include in the “Remarks” portion of the appropriate liaison form a statement that the coverage record should
be returned under the “alpha” name since there is no U.S. SSN at this time.
b.
Prepare an alpha diary for the normal diary period for requests from each country.
(See specific country subchapter for diary periods)
2. Claims authorizer
Claims Authorizer:
a.
Review the folder upon receipt of the foreign coverage record and determine if insured
status can be met using the provisions of a totalization agreement.
b.
If yes, send the claim to IBO where an SSN is assigned and the RSDI disallowance is
processed. When the claim is returned to the module, process the award.
c.
If no, send a second “abandoned” claim notice specifying that totalization benefits are not payable. Do not request
assignment of an SSN. Prepare an SSA-382-U2 listing. Return the alpha folder to IBO
to be stored in the abandoned claims file.
