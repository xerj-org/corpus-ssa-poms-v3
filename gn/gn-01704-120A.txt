SSA Program Operations Manual System (POMS) - GN 01704.120 - Totalization Status Code (TSC)
Effective Dates: 07/30/2014 - Present | 
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201704120 (fetched 2026-10-04)

A. Award
A1 - Used to indicate that a totalization claimant is insured using his foreign coverage
and has been awarded U.S. totalization benefits.
A2 - Used to indicate that a totalization claimant is insured using his Italian coverage,
has been awarded U.S. totalization benefits and Italian totalization benefits, and
the guaranteed minimum is involved. (See GN 01705.110 for an explanation of the guaranteed minimum provision.) (This code only applies
to the Italian agreement.)
