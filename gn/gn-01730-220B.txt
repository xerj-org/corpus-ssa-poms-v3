B. Description of form SSA-2960-U3-AU
The form consists of three pages.
•
Page 1 (Blue file copy) is written in English and is used for folder documentation.
•
Page 2 (White 1st Request Copy) is written in German and is the initial copy sent
to the Austrian agency.
•
Page 3 (Yellow follow-up copy) is written in German and is used as a follow-up request
when necessary.
