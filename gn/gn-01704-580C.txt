SSA Program Operations Manual System (POMS) - GN 01704.580 - Assigning Correct Type-of-Event (TOE) Codes to Requests for Totalization Development
Effective Dates: 01/18/2024 - Present | TN 7 (01-24)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0201704580 (fetched 2026-10-04)

C. TOE code 430
Show TOE code 430 on requests made for totalization claims restricted to foreign benefits
but filed with an agency of SSA (DO, FSP or INTPSC). For example:
1.
A request for a U.S. earnings record needed for inclusion with a claims package for
a foreign agency.
2.
A request to a DO or an FSP for evidence needed for inclusion with a claims package
for a foreign agency.
