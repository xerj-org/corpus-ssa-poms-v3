A. Procedure - when to use the SSA-L566-U2
Use the SSA-L566-U2 Title II application cover notice to transmit a Title II application
to the applicant for wet signature, request any needed information/evidence to either
adjudicate the application or close out the protective filing for the unsigned application.
NOTE: The preprinted notice is also available in Spanish (SSA-L566-U2 SP). Both the English
and Spanish versions are available on the Document Processing System (DPS). For the
Title XVI application cover notices see SI 00601.040.
