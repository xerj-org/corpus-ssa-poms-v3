C. Process - FFSCF screens
1. Accessing the FFSCF screens
Access FFSCF screens from:
SSA MAIN MENU, Selection #33 (PRISON SYSTEM/FUGITIVE FELONS) and PRISON SYSTEM/FUGITIVE
FELON SUBMENU, Selection #3 FUGITIVE FELON SSA CONTROL FILE (FFSCF))
For more detailed information on the Fugitive Felon SSA Control File Screens, see
MSOM PRISON 006.002.
