GN 01775.315 Romanian Unique Identifier
Romania introduced the Unique Identifier Code applied to all citizens. The Unique
Identifier Code is a standard identification number.
The Unique Identifier Code consists of 13 digits as follows:
If the fist digit is number 1, identifies person as male.
If the first digit is 2, identifies person as female.
Followed by date of birth (DDMMYYRR) and the remainder is a 6-digit serial number.
Gender code and Date of birth
A foreign born male code is 7.
A foreign born female code is 8.
A male born from 2000 code is 5.
A female born from 2000 code is 6.
The Unique Identifier Code is a lifetime number for Social security, health, and pension
for social programs with earnings and tax.
