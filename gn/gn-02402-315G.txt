G. Example of coding Barbados direct deposit
The customer provides us with a signup form for Barbados containing the account number:
“1234567890112233445566.”
1. Derive the RTN
The technician enters the information for the RTN.
•
Code the RTN of 700000177
•
Code the type of account as a “C” for checking or an “S” for savings. If no account
type indicated, use a “C” for checking.
2. Derive the DAN
The technician codes the DAN.
•
Start with the country code of “F” designated for Barbados; and
•
Code 12 digits of the account number “123456789011”
3. Obtain the following information
•
RTN: 700000177
•
Checking
•
DAN: F123456789011
a. POS reflects the direct deposit information
•
DIRECT DEPOSIT ROUTING TRANSIT NUMBER: 700000177 ACCOUNT TYPE (C/S): C
•
DEPOSITOR ACCOUNT NUMBER: F123456789011
•
CANCEL DIRECT DEPOSIT (Y):
•
DIRECT EXPRESS (Y):
b. The MBR reflects the following information
•
RTN- 700000177
•
DAN- CF123456789011
