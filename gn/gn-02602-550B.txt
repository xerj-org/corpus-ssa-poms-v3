B. Background for using the Centenarian Project website
This website lists all centenarians chosen for the project. Use the website to document
all contacts with the centenarians. Once you enter the interview information into
the Centenarian Project Website, it maintains all historical data about the centenarian. The case remains on the
list, but appears as complete. The Centenarian Project Worksheets are also located
on this website.
For more information on the Centenarian Project Worksheets, see GN 02602.560.
