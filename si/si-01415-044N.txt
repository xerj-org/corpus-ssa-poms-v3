N. Description of supplements for Rhode Island
1. Definitions of State living arrangement variations for Rhode Island
Definitions of State Living Arrangement Variations are as follows:
Code
Definition
D
Residential Care or Assisted Living – Apply this OS code to recipients only.
Y
Optional Supplementation Waived – Use this code to indicate that a recipient is eligible
for an optional supplement, but has waived their right to receive such.
Z
No State Supplement payable – The State of Rhode Island does not pay a supplement
unless recipient resides in a Licensed Adult Care Facility (“Residential Care or Assisted
Living”) as described in category “D”.
