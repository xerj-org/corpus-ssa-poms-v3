Does the class member still receive an augmented VA protected pension?
•
If yes, input the verified amount of VA income effective with the current calendar

If no, input a CG code of “AND2 MMYY”. Issue the form letter displayed in SI 00832.004 F. Complete the overprinted report of contact in SI 00832.004 H. Skip to 8.
3.
Complete the overprinted report of contact in SI 00832.004
H. to document the FO case file.
4.
Will your input cause the case to go into suspense (payment status N01)? If yes, go
to 5. If no, skip to 8.
5.
Suppress the automated overpayment notice in the same input used to post verified
VA income. (Do not suppress the automated Notice of Planned Action.)
6.
Query the SSR to establish the amount of the overpayment reflected on the SSR as a
result of this input after the income correction input has processed.
7.
Input a waiver determination and suppress the waiver notice. (See SI 00832.001D.3. for waiver determination inputs.)
8.
Complete a copy of the Anderson Case Report (SI 00832.004
G.). STOP.
