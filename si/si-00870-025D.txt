D. Processing PASS appeals
1. Processing PASS reconsideration requests
Refer to SI 00870.020E for instructions on processing PASS reconsiderations.
2. Processing PASS hearing requests
If an individual requests an appeal of the reconsideration determination made by a
PASS Specialist, follow the instructions for handling Title XVI hearing requests provided
in SI 04030.020 and MS 04420.001.
