M. Description of supplements for Rhode Island
1. Definitions of State living arrangement variations for Rhode Island
Definitions of State Living Arrangement Variations are as follows:
Code
Definition
D
Residential Care or Assisted Living
Apply OS code D to recipients only.
Y
Optional Supplementation Waived
Use OS code Y to indicate that a recipient is eligible for an optional supplement,
but has waived their right to receive such.
Z
No State Supplement payable
Code Z means the State of Rhode Island does not pay a supplement unless the recipient
resides in a Licensed Adult Care Facility (“Residential Care or Assisted Living”)
as described in category “D”.
