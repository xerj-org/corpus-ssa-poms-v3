SSA Program Operations Manual System (POMS) - SI 01150.100 - Processing Resource Transfers Occurring Before 12/14/99
Effective Dates: 01/09/2007 - Present | TN 12 (08-00)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0501150100 (fetched 2026-10-04)

A. Introduction
A resource transfer does not affect SSI resource eligibility if it occurred before
12/14/99 but it could affect eligibility for Medicaid. Also, if the resource was not
validly transferred, it may still be a countable resource. Therefore, we develop transfers
that occur before 12/14/99. This section provides instructions for processing cases
in which a resource transfer occurred prior to 12/14/99.
