G. Procedure - Spanish Language Indicator On Record
If applicable, use the Spanish version of the Form Letter for Eligible Individuals
in SI 00502.450B.
NOTE: There is no existing Spanish cover letter for this situation.
If applicable, use the Spanish versions for other notice paragraphs, which follow
the English text.
NOTE: This language will be on the Spanish Field Office Notice Software (FONS) screens.
For English and Spanish versions of cover letters that provide appeals rights in Spanish
for award, denial and most posteligibility situations, see NL 00801.025.
