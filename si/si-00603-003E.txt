E. Procedure - Systems Input
For paper applications, input code DEF in the Applications Characteristics (AC) field
(SM 01005.650) and code H80 in the payment status (PS) field on an SSA-450-SI (SSI
Data Input and Determination) (SM 01010.055).
NOTE: In MSSICS, Build Transaction SSR (BTS) will build these fields automatically.
