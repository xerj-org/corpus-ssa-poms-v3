A. Introduction to the interim assistance reimbursement (IAR) Activity List
The IAR Activity Lists generated from the Supplemental Security Record (SSR) identifies
Supplemental Security Income (SSI) initial claim (IC) and posteligibility (PE) transactions
by:
•
State and local jurisdictions;
•
grant reimbursement code (GRC); and
•
claimants' names in alphabetical order.
The SSI system electronically transmits the activity lists each month to the regional
offices (RO). The legend appearing at the top of each list indicates whether it pertains
to IC or PE cases.
