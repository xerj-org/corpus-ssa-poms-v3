F. Procedure for coding trusts
1. Coding Medicaid trusts on paper
Code a Q and the date of establishment of the trust in the Third-Party Liability (PT) field
of the Supplemental Security Record (SSR) if the trust qualifies as a Medicaid Trust.
2. Coding the CG field
Code RE06 or RE07, as applicable in the CG (case characteristics) field to indicate a revocable or
irrevocable trust, respectively. For a list of CG code entries, see SM 01301.820.
