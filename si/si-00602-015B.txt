SSA Program Operations Manual System (POMS) - SI 00602.015 - Completing the SSA-8000-BK (Application for Supplemental Security Income (SSI)) as an Abbreviated Application (ABAP)
Effective Dates: 04/11/2007 - Present | TN 8 (05-20)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0500602015 (fetched 2026-10-04)

B. Mandatory items to complete when using the SSA-8000-BK as an ABAP
Complete these items on the SSA-8000-BK as an ABAP:
•
Write “ABAP” in the upper right-hand corner;
•
Telephone (TEL) block, if appropriate;
•
Date block;
•
Preferred Language, if appropriate;
•
Type of Claim;
•
Questions 1, 2, 3, and 5 through 8 (including sub-items of these questions). Currently,
the SSI Claims System also requires answers to 18, 19, 20, 58, and 64;
•
Items 40 through 50 and 56, if appropriate; and
•
Tear-off page ("Receipt for Claim") portion per the instructions on completing the
receipt for claim and changes to report tear off page in SI 00604.120. Discuss any pre-checked or unmarked item(s) that relate(s) to the reason for denial
on the "Changes to Report" portion.
