SSA Program Operations Manual System (POMS) - SI 02305.070 - When to Use the SSI Claims System or the Paper RZ Form SSA-8203-BK, Statement for Determining Continuing Eligibility for Supplemental Security Income Payments
Effective Dates: 09/15/2026 - Present | TN 105 (09-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0502305070 (fetched 2026-10-04)

B. When to use the SSI Claims System
Use the SSI Claims System to conduct RZs whenever possible. Document Redeterminations
that cannot be completed in the SSI Claims System on an SSA-8203-BK, Statement for
Determining Continuing Eligibility for Supplemental Security Income Payments. For
a list of conditions that might require a redetermination to be processed on paper
rather than in the SSI Claims System see MS 08101.004.
