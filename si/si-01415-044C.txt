C. Description of supplements for Delaware
1. Definitions of State living arrangement variations for Delaware
Code
Definition
A
Adult Residential Care Facility, Assisted Living Facility, or Adult Foster Care Home
– To be eligible for this category the State must provide documentation that a recipient
is a resident of a certified Adult Residential Care Facility, Assisted Living Facility,
or Adult Foster Care Home.
Y
Optional Supplementation Waived – Use this code to indicate that a recipient is eligible
for an optional supplement, but has waived their right to receive such.
Z
No Supplement Cases – Use this code for any recipient who is not included in OS categories
A or Y.
Alternately, use OS code “Z” when the recipient is an “intervening” Federal code A.
For more information on Optional State Supplement codes see SM 01301.535
