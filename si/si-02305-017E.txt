E. Procedure on Organizing RZs, LIs and Manual Deemed Income Workloads
Organize your redetermination cases following the order of priority below. Treat RZs
and LIs with the same priority in the redetermination workload.
Order of Priority
1.
Profile C with priority diary
2.
LI with priority diary
3.
Profile E and M
4.
Profile K
5.
Profile C without a priority diary
6.
Profile B, UC 1, and W with priority diaries
7.
Profile A with priority diary
8.
LI without priority diary
9.
1619(a) cases with a special action code A
10.
Profile UC 1 and W without priority diaries
11.
Profile A and B without priority diaries
NOTE: You may use the (StaRZ and Stripes the Next Generation (SSTNG) ) system to select your workload using profiles and diaries. The intranet site contains
user instructions.
