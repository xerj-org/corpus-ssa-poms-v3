E. Appeals related to a particular resource
If a claimant appeals a denial related to a particular resource, the evidence in file
or on the evidence screen must clearly establish the value of that resource even if
the issue under appeal is not the value itself (e.g., when the issue under appeal
is ownership).
If an allegation conflicts with existing evidence, resolve the discrepancy. For more
information, see What is Evidence GN 00301.010 and Resolving Conflicts in Evidence GN 00301.040.
These requirements ensure that at each level in the appeals process, the evidence
screen or file contains complete documentation of the resource in question.
