SSA Program Operations Manual System (POMS) - SI 02305.070 - When to Use the SSI Claims System or the Paper RZ Form SSA-8203-BK, Statement for Determining Continuing Eligibility for Supplemental Security Income Payments
Effective Dates: 09/15/2026 - Present | TN 105 (09-26)
Source: https://secure.ssa.gov/apps10/poms.nsf/lnx/0502305070 (fetched 2026-10-04)

E. Definitions
1. Discrepancy
A discrepancy is a conflict between the recipient's allegations and prior information
SSA has. For the definition of prior information see SI 02305.070F.3.
2. Reference date
The reference date is the retroactive date to which the recipient refers when responding to questions
on RZ forms. To determine the reference date see SI 02305.034C.
3. Prior information
Prior information means information housed in any of the following items:
•
SSI Claims System screens;
•
System queries;
EXAMPLES: DEQY, SEQY, SSID, SSI3, etc.
•
All forms completed during the RZ;
•
Prior files housed in the FO (these files should be consolidated);
•
Initial claim folders being retained in the FO
•
Manual or computer listings.
