C. Description of Form SSA-8203-BK - Question 25
Question
25
This question is divided into several parts:
a.
Are you currently receiving SNAP?
If YES, go to "b." If NO, go to "c.
b.
Have you received a recertification notice within the past 30 days?
If YES, go to "e." If NO, go to question 26.
c.
Have you filed for SNAP in the last 60 days?
If YES, go to "d." If NO, go to "e."
d.
Have you received a favorable decision?
If YES, go to question 26. If NO, go to "e."
e.
Is everyone in the household applying for or receiving SSI?
If YES, go to "f." If NO, go to question 26.
f.
May I take your SNAP application today?
If YES, go to question 26. If NO, explain in "g."
g.
Explanation
