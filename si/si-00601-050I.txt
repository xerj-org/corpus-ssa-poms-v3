I. Procedure -- documenting a request for withdrawal
NOTE:
There is no particular form for requesting a withdrawal of an SSI application.
1. Request prepared by the individual
If the individual submits a written request containing all the elements described
in SI 00601.050D.2., do not request anything further.
2. Request prepared by FO
If you have the opportunity to prepare a document for the individual's signature,
prepare it on a SSA-795 (Statement of Claimant or Other Person). If possible, generate
the SSA-795 using the Consolidated Claims Experience (CCE) by selecting "add person
statement" on the Person Statement screen in the CCE Development Menu.
