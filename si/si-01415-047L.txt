L. Description of supplements for Rhode Island
1. Definitions of State living arrangement variations for Rhode Island
Definitions of State Living Arrangement Variations are as follows:
Code
Definition
D
Residential care or assisted living
Apply OS code “D” only to recipients living in residential care or assisted living
facilities.
Y
Optional supplementation waived
Use OS code “Y” to indicate that a recipient is eligible for an optional supplement,
but waived their right to receive supplementation.
Z
No state supplement payable
Use OS code “Z” when the State of Rhode Island does not pay a supplement unless the
recipient resides in a licensed adult care facility (“residential care or assisted
living”) s described in category “D”.
