B. Description of the IAR Activity List
The RO uses the IAR Activity List to select the IAR cases to review.
1. IC Activity List description
The IC Activity List identifies awarded and denied claims. The list shows the amount
of retroactive SSI payments for allowances. The IC Activity List contains the following
information:
•
GRC of State/county agency authorized for reimbursement
•
Full name of claimant
•
Social Security number (SSN)
•
Type of action (paid, denied, no retroactive payment due)
•
Denial date (if denied)
•
Eligibility date (if eligible)
•
Date of payment to State, or date of payment to claimant if no retroactive amount
due
•
State and county code of residence
•
Amount of the payment
•
Servicing field office (FO) code
2. PE Activity List description
The PE Activity List identifies PE cases that have retroactive payments, the amount
of the SSI payments, if any, and cases with no retroactive SSI payments. The PE Activity
List contains the following information:
•
GRC of State/county agency authorized for reimbursement
•
Full name of claimant
•
SSN
•
Date of payment to the State, or date of payment to the claimant if no retroactive
amount due
•
State and county code of residence
•
Amount of the payment
•
Servicing FO code
